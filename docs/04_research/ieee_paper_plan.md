# IEEE Paper Plan

## Paper 1

### Title

Compute-Aware Configuration Tuning for Local Large Language Models on Consumer Hardware

### Contribution

A framework for evaluating local LLM configurations on fixed consumer hardware using quality, speed, memory efficiency, and feasibility metrics.

### Required Deliverables

- Benchmark suite
- Hardware profile
- Prompt set
- Model configuration matrix
- CSV dataset
- Graphs
- Ranking formula
- Paper draft

### Target Sections

1. Introduction
2. Related Work
3. Problem Definition
4. Methodology
5. Benchmark Setup
6. Results
7. Discussion
8. Limitations
9. Conclusion

## Paper 2

### Title

Hardware Decision Maps for Local LLM Deployment Under RAM and VRAM Constraints

### Contribution

Decision maps that recommend model size, quantization, and context length under RAM/VRAM constraints.

### Required Deliverables

- Multi-hardware benchmark dataset
- RAM/VRAM model-fit tables
- Latency graphs
- Tokens/sec graphs
- Decision maps
- Recommendation tables

## Paper 3

### Title

AI Privilege Broker: Controlled Privileged Execution for Local AI Operating System Assistants

### Contribution

A privilege broker architecture that prevents local AI assistants from executing privileged system actions without policy checks, approval, and audit logs.

### Required Deliverables

- Privilege broker prototype
- Risk classifier
- Command policy file
- Approval flow
- Audit log
- Safety evaluation

## Paper 4

### Title

Rollback, Audit Logging, and Human Approval for Safe AI-Assisted System Administration

### Contribution

A safety evaluation of approval workflows, audit logs, rollback, and blocked-command handling for local AI system administration.

### Required Deliverables

- Rollback mechanism
- Audit schema
- User approval workflow
- Safe/unsafe task dataset
- Safety evaluation report

## Paper 5

### Title

An Integrated Compute-Aware Local AI System for Safe Offline System Assistance

### Contribution

An end-to-end local AI system that selects a model based on hardware and uses it for safe Linux assistance through a privilege broker.

### Required Deliverables

- Integrated prototype
- End-to-end demos
- Architecture diagrams
- System evaluation
- Usability observations
- Final paper draft
