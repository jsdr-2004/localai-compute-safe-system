# Research Reproducibility Checklist

- [ ] Hardware profile and hardware profile ID recorded.
- [ ] Operating system and kernel recorded.
- [ ] Python version and package version recorded.
- [ ] Ollama version recorded.
- [ ] Installed model list and exact model tags recorded.
- [ ] Unique `run_id` recorded.
- [ ] Git commit hash and dirty status recorded.
- [ ] Benchmark config snapshot saved.
- [ ] Prompt suite snapshot saved.
- [ ] Environment metadata saved.
- [ ] Raw outputs saved.
- [ ] CSV and JSONL results saved.
- [ ] Individual failures and error messages saved.
- [ ] Graph outputs saved.
- [ ] Recommendations generated.
- [ ] Human quality-scoring status documented.
- [ ] Experimental limitations documented.
- [ ] Power, thermal, and background-process conditions noted.
