# Reproducibility Checklist

- [ ] Save the hardware profile JSON with results.
- [ ] Record OS, kernel, Python, Ollama, and model versions.
- [ ] Preserve benchmark YAML and prompt JSON.
- [ ] Keep power mode and thermal conditions stable.
- [ ] Run every matrix item and record failures.
- [ ] Use at least three repeats for research runs.
- [ ] Preserve CSV, JSONL, and raw outputs.
- [ ] Document human quality-scoring rubric and reviewers.
- [ ] Generate reports from the unmodified result dataset.
- [ ] Record policy YAML used for safety evaluations.
