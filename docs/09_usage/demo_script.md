# Demo Script

1. Profile the machine with `python -m localai_system hardware print`.
2. Validate and dry-run the Ollama benchmark matrix.
3. Generate recommendations and graphs from sample data.
4. Classify `df -h`, `sudo apt install docker.io`, and `rm -rf /`.
5. Launch `python -m localai_system assistant` without `--execute`.
6. Ask for disk usage, Docker installation, and deletion of all files.
7. Show that all proposals are logged and the destructive request is blocked.
8. Inspect events with `python -m localai_system audit list`.
