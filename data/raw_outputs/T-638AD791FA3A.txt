Here are some safe and effective Linux commands to check disk usage:

### 1. Using `df` Command
```bash
df -h / | grep "Total"
```
This command displays the total amount of disk space used by each partition, along with its percentage.

### 2. Using `du` Command
```bash
du -h / | grep "Total"
```
This command displays the total amount of disk space used by each directory, along with its percentage.

### 3. Using `fsck` Command (for ext4 file system)
```bash
fsck -f / | grep "Error"
```
This command checks for errors in the file system and reports any issues found.

### 4. Using `df -Bp` Command (for partition-based disk usage)
```bash
df -Bp / | grep "Total"
```
This command displays detailed information about each partition, including its size, used space, and percentage.

### 5. Using `cat /proc/meminfo` Command (for system-wide memory usage)
```bash
cat /proc/meminfo
```
This command displays system-wide information about memory usage, including the total amount of RAM used.

### 6. Using `free -m` Command (for system-wide disk usage)
```bash
free -m | grep "Mem"
```
This command displays detailed information about system-wide memory usage, including the total amount of RAM used and the amount of free memory available.

Remember to always use these commands with caution and in a controlled environment, as they can potentially reveal sensitive information about your system.
