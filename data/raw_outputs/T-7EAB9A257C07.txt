Certainly! Below is a simple Python function that takes a string as input and returns the reversed version of the string.

```python
def reverse_string(input_string):
    """
    This function takes a string as input and returns its reversed version.
    
    :param input_string: The original string to be reversed.
    :return: A new string which is the reverse of the input string.
    """
    return input_string[::-1]

# Example usage:
original_string = "hello"
reversed_string = reverse_string(original_string)
print(f"Original String: {original_string}")
print(f"Reversed String: {reversed_string}")
```

In this function, I used Python's slicing feature (`input_string[::-1]`), which creates a new string that includes every other character from the end of the original string. This effectively reverses the order of characters in the string.

You can test this function with different strings to see how it works:

```python
# Test the reverse_string function
print(reverse_string("hello"))  # Output: "olleh"
print(reverse_string(""))        # Output: ""
print(reverse_string("a"))       # Output: "a"
print(reverse_string("ab"))      # Output: "ba"
```

If you need a different approach, such as using loops to reverse the string manually, here is an example of that:

```python
def manual_reverse(input_string):
    """
    This function takes a string and returns its reversed version by manually iterating through characters.
    
    :param input_string: The original string to be reversed.
    :return: A new string which is the reverse of the input string.
    """
    reversed_str = ""
    for char in input_string:
        reversed_str = char + reversed_str
    return reversed_str

# Test the manual_reverse function
print(manual_reverse("hello"))  # Output: "olleh"
print(manual_reverse(""))        # Output: ""
print(manual_reverse("a"))       # Output: "a"
print(manual_reverse("ab"))      # Output: "ba"
```

Both functions will give you the same output, but `reverse_string` is generally considered more Pythonic and efficient for this task.
