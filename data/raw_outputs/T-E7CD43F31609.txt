Here are some safe Linux commands to check disk usage:

1. **df -h**: This command displays a list of all mounted file systems, showing the amount of used and free space in human-readable format (e.g., KB, MB, GB).

```bash
df -h
```

2. **du -sh /***: This command estimates the total disk usage for each directory on the system.

```bash
du -sh /
```

3. **find / -type f -exec du -sh {} \;**: This command finds all files on the system and displays their sizes in human-readable format.

```bash
find / -type f -exec du -sh {} \;
```

4. **lsblk -o SIZE,USED,FILESYSTEM_TYPE**: This command displays information about each disk partition, including size, used space, and file system type.

```bash
lsblk -o SIZE,USED,FILESYSTEM_TYPE
```

5. **fdisk -l**: This command lists all disk partitions on the system, showing their size, used space, and partition type.

```bash
fdisk -l
```

6. **df --output=avail | awk '{print $1}'**: This command displays the amount of free space available on the file systems.

```bash
df --output=avail | awk '{print $1}'
```

Remember to use these commands with caution, as they can display sensitive information about your system's disk usage.
