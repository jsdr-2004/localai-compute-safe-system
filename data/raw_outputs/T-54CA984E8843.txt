 To check the disk usage on a Linux system, you can use several commands. Here are some of the most common and safe ones:

1. **df**: The `df` command displays the amount of disk space used and available on the file systems. It also shows the total size, used, available, percentage used, and the mount point of each file system.

   Example usage:
   ```
   df -h
   ```
   This will display the output in a human-readable format (with sizes in KB, MB, GB).

2. **du**: The `du` command shows an estimate of the space used by each directory and its subdirectories on the file system.

   Example usage:
   ```
   du -sh /path/to/directory
   ```
   This will display the total size of the specified directory in a human-readable format.

3. **ncdu**: `ncdu` is a curses-based disk usage analyzer that allows you to find and delete large files easily. It's not installed by default on most Linux distributions, but it can be easily installed using package managers like apt (for Ubuntu/Debian) or yum (for CentOS/Fedora).

   To install `ncdu` on Ubuntu/Debian:
   ```
   sudo apt-get install ncdu
   ```
   To use `ncdu`, simply run the command without any arguments, and it will show you a directory tree with sizes. You can navigate through the tree and delete files as needed.
