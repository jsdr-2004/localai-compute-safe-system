Certainly! Below is a simple and efficient Python function that reverses a given string:

```python
def reverse_string(s):
    """
    Reverses the input string.

    Parameters:
    s (str): The string to be reversed.

    Returns:
    str: The reversed string.
    """
    return s[::-1]

# Example usage:
original_string = "Hello, World!"
reversed_string = reverse_string(original_string)
print(f"Original String: {original_string}")
print(f"Reversed String: {reversed_string}")
```

### Explanation:
- `s[::-1]`: This is a slicing operation in Python. The syntax `s[start:end:step]` means to take all elements from the start of the string (`start` defaults to 0) up to but not including the element at position `end`. By setting `start` and `end` to `None` (which corresponds to starting from the beginning and going to the end), and specifying `-1` as the step, we effectively slice the entire string in reverse order.

This function is efficient and concise. It does not require any external libraries and works with basic Python string handling capabilities.
