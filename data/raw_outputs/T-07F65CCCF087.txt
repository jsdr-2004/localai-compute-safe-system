 Sure! Here's a simple Python function that reverses a given string:

```python
def reverse_string(input_string):
    return input_string[::-1]
```

In this function, `[::-1]` is a slice operation in Python. It returns the reversed sequence of elements in the original string. You can call this function with any string you'd like to reverse:

```python
print(reverse_string("Hello, World!"))  # Outputs: !dlroW ,olleH
```
