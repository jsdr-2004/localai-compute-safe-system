### Reversing a String in Python

You can use the built-in `reversed` function and the `join` method to reverse a string in Python.

#### Code
```python
def reverse_string(s):
    """
    Returns the reversed string.

    Args:
        s (str): The input string.

    Returns:
        str: The reversed string.
    """
    return ''.join(reversed(s))

# Example usage:
print(reverse_string("hello"))  # Output: "olleh"
```

#### Explanation

*   The `reversed` function returns a reverse iterator of the input sequence (in this case, a reverse iterator over the characters in the string).
*   The `join` method concatenates all the elements of the reverse iterator into a single string.

Alternatively, you can use slicing to reverse a string:

#### Code
```python
def reverse_string(s):
    """
    Returns the reversed string.

    Args:
        s (str): The input string.

    Returns:
        str: The reversed string.
    """
    return s[::-1]

# Example usage:
print(reverse_string("hello"))  # Output: "olleh"
```

#### Explanation

*   The `s[::-1]` syntax tells Python to start at the end of the string and move backwards to the beginning, stepping backwards by 1 character each time. This effectively reverses the string.

Both methods produce the same result, but the slicing method is often more concise and readable.
