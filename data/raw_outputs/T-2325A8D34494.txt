### Reversing a String in Python

You can use the built-in `reversed()` function in combination with the `join()` method or the slicing syntax to reverse a string in Python.

#### Using Slicing Syntax

```python
def reverse_string(s):
    """
    Returns the reversed string.

    Args:
        s (str): The input string.

    Returns:
        str: The reversed string.
    """
    return s[::-1]
```

This function uses slicing to extract characters from the end of the string and concatenate them in reverse order. The `::-1` slice means "start at the end of the string and end at position 0, move with the step -1".

#### Using `reversed()` Function

```python
def reverse_string_reversed(s):
    """
    Returns the reversed string.

    Args:
        s (str): The input string.

    Returns:
        str: The reversed string.
    """
    return "".join(reversed(s))
```

This function uses the `reversed()` function to iterate over the characters in the string and join them back into a single string using the `"".join()` method.

#### Example Usage

```python
print(reverse_string("Hello World"))  # Output: "dlroW olleH"
print(reverse_string_reversed("Python is fun"))  # Output: "nuf si nohtyP"
```

These functions can be used to reverse any string in Python.
