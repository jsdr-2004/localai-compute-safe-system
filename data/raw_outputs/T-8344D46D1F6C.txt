### Reversing a String in Python

You can use the following Python function to reverse a string:

```python
def reverse_string(input_str):
    """
    Reverses the input string.

    Args:
        input_str (str): The string to be reversed.

    Returns:
        str: The reversed string.
    """
    return input_str[::-1]
```

### Explanation

This function uses slicing with a step of `-1` to reverse the string. Here's how it works:

* `input_str[::-1]`: This is slicing the string from the end, starting at the second character (`index 1`) and ending at the beginning.
* The `::-1` step means "start at the end and end at position 0", which effectively reverses the string.

### Example Use Cases

```python
print(reverse_string("hello"))  # Output: olleh
print(reverse_string("Python is awesome!"))  # Output: !emosewa si nohtyP
```

Note that this function does not handle non-string inputs or edge cases. You may want to add error checking to handle these scenarios if needed.
