 To check the disk usage on a Linux system, you can use several commands. Here are some of the most common ones:

1. **df**: The `df` command displays the amount of disk space used and available on your file systems. It also shows the number of inodes used and available.

   Syntax: `df [options] [file]`

   For example, to display the disk usage for all file systems, you can use:

   ```
   df -h
   ```

   The `-h` option makes the output human-readable by showing sizes in a format like KB, MB, GB, etc.

2. **du**: The `du` command estimates file and directory space usage. It's useful when you want to check the disk usage of a specific directory or file.

   Syntax: `du [options] [directory]`

   For example, to display the size of the /home directory in a human-readable format, use:

   ```
   du -sh /home
   ```

3. **ncdu**: If you prefer a graphical interface for disk usage analysis, you can install `ncdu` (Ncurses Disk Usage) using the package manager of your Linux distribution. Once installed, you can run it with:

   ```
   ncdu
   ```

   This command will recursively scan your file system and display a tree view of directories sorted by size. You can navigate through the directory structure and get detailed information about disk usage.
