Here are some safe and effective Linux commands to check disk usage:

### 1. Using `df` Command

The `df` command displays the disk usage information for all partitions on your system.

```bash
df -h
```

This will show you a summary of the disk usage, including the total size, used space, and available space for each partition.

### 2. Using `du` Command (for small files)

The `du` command is useful for checking the disk usage of small files.

```bash
du -h /path/to/your/directory
```

This will show you the disk usage in a human-readable format, including the total size and used space for each file.

### 3. Using `fsck` Command (for ext2, ext3, and ext4 filesystems)

The `fsck` command is useful for checking the integrity of your filesystems.

```bash
fsck -f /path/to/your/directory
```

This will scan your filesystem for errors and report any issues found. If you're using an ext2, ext3, or ext4 filesystem, this command may also help you identify disk corruption.

### 4. Using `mount` Command (for checking mount points)

The `mount` command is useful for checking the mount points of your filesystems.

```bash
mount | grep "sysfs"
```

This will show you the mount point and device name for each filesystem on your system.

### 5. Using `lsblk` Command (for disk usage information)

The `lsblk` command provides detailed information about all disks on your system, including their usage statistics.

```bash
lsblk -o "FSTYPE", "SIZE", "NAME" /dev/sdx
```

Replace `/dev/sdx` with the device name of the disk you want to check. This will show you a summary of the disk usage for each partition.

### 6. Using `df -T` Command (for detailed disk usage information)

The `df -T` command provides more detailed information about the disk usage, including the mount point and filesystem type.

```bash
df -T /path/to/your/directory
```

This will show you a summary of the disk usage for each partition on your system.
