Certainly! Here's a simple and straightforward way to create a Python function that reverses a given string:

```python
def reverse_string(s):
    """
    Reverses the input string.

    Parameters:
    s (str): The string to be reversed.

    Returns:
    str: The reversed string.
    """
    return s[::-1]

# Example usage:
original_string = "hello"
reversed_string = reverse_string(original_string)
print(f"Original String: {original_string}")
print(f"Reversed String: {reversed_string}")
```

In this function, the slicing operator `[::-1]` is used to reverse the string. This method creates a new string that starts from the last character and moves backwards by one step at a time.

Here's an alternative approach using Python's built-in `reversed()` function:

```python
def reverse_string(s):
    """
    Reverses the input string.

    Parameters:
    s (str): The string to be reversed.

    Returns:
    str: The reversed string.
    """
    return ''.join(reversed(s))

# Example usage:
original_string = "hello"
reversed_string = reverse_string(original_string)
print(f"Original String: {original_string}")
print(f"Reversed String: {reversed_string}")
```

In this alternative method, the `reversed()` function returns an iterator that can be converted into a string with `''.join()`. Both methods will produce the same result.
