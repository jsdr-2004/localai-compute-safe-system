### Reversing a String in Python

Here's a simple and efficient way to reverse a string in Python:

```python
def reverse_string(s):
    """
    Returns the reversed version of the input string.

    Args:
        s (str): The input string to be reversed.

    Returns:
        str: The reversed string.
    """

    # Check if the input is a string
    if not isinstance(s, str):
        raise TypeError("Input must be a string.")

    # Use slicing with a step of -1 to reverse the string
    return s[::-1]
```

### Example Usage:

```python
# Test the function
print(reverse_string("Hello World"))  # Output: "dlroW olleH"
```

This function uses Python's slice notation `s[start:stop:step]` where:

- `start`: The starting index of the slice (default is 0).
- `stop`: The ending index of the slice (default is the end of the string).
- `step`: The increment between elements in the slice (default is 1).

By setting `step=-1`, we effectively reverse the string.
