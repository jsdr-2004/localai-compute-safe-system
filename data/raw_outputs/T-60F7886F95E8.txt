**Reversing a String in Python**
=====================================

Here is a simple and efficient way to reverse a string in Python:

```python
def reverse_string(s):
    """
    Reverses the input string.

    Args:
        s (str): The input string to be reversed.

    Returns:
        str: The reversed string.
    """
    return s[::-1]
```

**Explanation**
---------------

This function uses Python's slice notation to extract characters from the beginning of the string and append them to the end. The `[::-1]` slice means "start at the end of the string and end at position 0, move with the step -1".

**Example Use Cases**
---------------------

```python
print(reverse_string("hello"))  # Output: "olleh"
print(reverse_string("abcde"))  # Output: "edcba"
```

Note that this function does not modify the original string. Instead, it returns a new reversed string. If you want to modify the original string, you can use slicing with the `replace` method:

```python
def reverse_string_original(s):
    s = s[::-1]
    return s.replace(" ", "")  # Remove spaces from the end of the string

print(reverse_string_original("hello"))  # Output: "olleh"
```

In this case, we assign the reversed string back to `s` and then remove any leading or trailing whitespace using `replace`.
