Here are some safe and common Linux commands to check disk usage:

1. **df** (Disk Free) command:
   ```bash
df -h
```
   This command displays the current disk usage, available space, and file system type for each mounted partition.

2. **du** (Disk Usage) command:
   ```bash
du -sh /
```
   This command estimates the size of the root directory and its contents in a human-readable format.

3. **fsck** (File System Check) command:
   ```bash
fsck -n /dev/sda1
```
   This command checks the file system for errors without making any changes to the file system. The `-n` option prevents fsck from mounting the file system automatically.

4. **mount** command with `-v** option:
   ```bash
mount -v /dev/sda1 /mnt
```
   This command mounts a partition and displays detailed information about the mount process, including disk usage.

5. **lsblk** (List Block Devices) command:
   ```bash
lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT,USE
```
   This command lists block devices with their file system type, size, mount point, and usage percentage.

6. **pmap** (Process Memory Information) command:
   ```bash
pmap -d <process_id>
```
   This command displays the memory map of a specific process, including its disk usage.

Remember to replace `<process_id>` with the actual ID of the process you want to check.

These commands will help you monitor and manage your Linux system's disk usage effectively.
