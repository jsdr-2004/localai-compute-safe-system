 Here is a simple Python function that reverses a given string:

```python
def reverse_string(input_str):
    return input_str[::-1]
```

In this function, `[::-1]` is a slice notation in Python that reverses the order of elements in a sequence (like strings or lists). The `reverse_string` function takes an input string and returns its reverse.

You can use it like this:

```python
print(reverse_string("Hello World"))  # Output: dlroW olleH
```
