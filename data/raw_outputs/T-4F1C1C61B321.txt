### Reversing a String in Python
#### Function Definition

```python
def reverse_string(input_str):
    """
    Returns the reversed input string.

    Args:
        input_str (str): The string to be reversed.

    Returns:
        str: The reversed input string.
    """
    return input_str[::-1]
```

#### Explanation

This function uses Python's slice notation to create a new string that is the reverse of the original. The `[::-1]` syntax tells Python to start at the end of the string and move backwards to the beginning, stepping backwards by 1 character each time.

#### Example Usage

```python
print(reverse_string("Hello World"))  # Output: "dlroW olleH"
```

Alternatively, you can use a for loop to achieve the same result:

```python
def reverse_string(input_str):
    reversed_str = ""
    for char in input_str:
        reversed_str = char + reversed_str
    return reversed_str
```

This function iterates over each character in the input string and prepends it to the `reversed_str` variable, effectively reversing the string.
