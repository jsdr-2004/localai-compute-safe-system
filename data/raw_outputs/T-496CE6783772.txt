 Here are some common Linux commands that can help you check disk usage:

1. `df -h` : This command shows the amount of disk space used and available on your file system, along with other useful information like the file system type and mount point. The `-h` option makes the output easier to read by showing sizes in a human-friendly format (e.g., KB, MB, GB).

2. `du -sh *` : This command shows the total size of each directory and file in the current directory. The `-s` option tells du to only show the total for each directory, while the `*` wildcard matches all files and directories within the current directory.

3. `ncdu` : ncdu is a curses-based disk usage analyzer that provides an interactive tree view of your file system. To install it on Ubuntu/Debian, run `sudo apt-get install ncdu`. Once installed, you can use the command `ncdu .` to analyze the current directory.

4. `top -b -n 1 | grep Cpu` : This command displays a list of running processes and their resource usage. The output is sorted by CPU usage by default. While not directly related to disk usage, it can still provide valuable insights into which programs may be consuming significant system resources that could impact disk performance.

5. `iostat -x 5` : This command provides information about the I/O (input/output) activity on your system's disks. It shows statistics for both CPU usage by the I/O scheduler and device-specific I/O data transfer rates, latency, and queue lengths. The `-x` option includes a more detailed breakdown of I/O operations, and the `5` specifies that it should run for 5 seconds and update every second.
