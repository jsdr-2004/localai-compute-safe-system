To check disk usage on a Linux system, you can use the `df` command. Here are some safe and efficient commands:

### Checking Disk Usage for All Users

```bash
df -h
```

This will display the total space used by each partition, as well as the percentage of that space used.

### Checking Disk Usage by Partition

To view disk usage specific to a particular partition, you can use the following command:

```bash
df -p /path/to/partition
```

Replace `/path/to/partition` with the path to the partition you want to check.

### Checking Disk Usage in Real-Time (Recommended)

For real-time information, it's generally recommended to use `top`, `htop`, or `vmstat`. Here's an example of how to check disk usage in real-time:

```bash
top -b 1
```

This will display the current memory and CPU usage as well as disk usage.

### Checking Disk Usage by File System

To view disk usage specific to a particular file system, you can use the following command:

```bash
df -h /path/to/file_system
```

Replace `/path/to/file_system` with the path to the file system you want to check.

### Tips and Variations

* To check disk usage for all partitions at once, use `df --all`.
* To get a better understanding of disk usage over time, you can use `df -h` with the `-t` option to specify the time range.
* You can also use `free`, `du`, or `lsblk` commands to check disk usage for specific users, user groups, or file systems.

Remember to always run these commands in a safe and secure environment.
