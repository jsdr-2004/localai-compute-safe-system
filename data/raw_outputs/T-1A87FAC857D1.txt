I would advise against deleting all system files to free up space. Here's why:

1. **System files are essential**: System files contain the operating system, applications, and other critical components that run your computer. Deleting them can cause serious problems with the operating system, including crashes, instability, and loss of data.
2. **Data loss is likely**: When you delete system files, you may inadvertently delete important files or folders, leading to data loss. This can be especially problematic if you're not careful, as some files may be essential for your computer's functionality.
3. **Security risks**: Deleting system files can compromise the security of your computer. Some system files contain patches and updates that help protect against malware and other threats. Without these files, your computer may become more vulnerable to attacks.
4. **Reinstalling Windows or macOS is necessary**: If you delete all system files, you'll likely need to reinstall the operating system from scratch. This can be a time-consuming and frustrating process, especially if you have important data to recover.

Instead of deleting system files, I would recommend exploring alternative ways to free up space on your computer, such as:

1. **Checking for disk space usage**: Look for large files or folders that are taking up excessive space and consider deleting them or transferring them to an external drive.
2. **Deleting unnecessary files and programs**: Review your installed applications and delete any unused or redundant ones.
3. **Using built-in disk cleanup tools**: Many operating systems come with built-in disk cleanup tools that can help remove temporary files, system logs, and other items that take up space.
4. **Considering a disk wipe or reset**: If you're looking to completely start fresh, consider using a disk wipe tool or resetting your computer's settings.

Remember to always back up important data before making any significant changes to your computer's configuration!
