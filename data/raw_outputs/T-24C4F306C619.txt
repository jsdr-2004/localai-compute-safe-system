Certainly! Here are some safe and useful Linux commands for checking disk usage:

1. **`df -h`**:
   This command is used to display file system disk space information in a human-readable format (e.g., gigabytes or megabytes). The `-h` option makes the output more readable.

   ```sh
   df -h
   ```

2. **`du -ah`**:
   `du` stands for "disk usage". This command is used to display disk usage of directories and files in a hierarchical format, with an additional `-a` flag that shows all files (including hidden ones) and the `-h` flag makes it more readable.

   ```sh
   du -ah
   ```

3. **`du --max-depth=1 /path/to/directory`**:
   This command is similar to `du -ah`, but you can specify a directory path to get disk usage for that specific directory and its contents at the first level only.

   ```sh
   du --max-depth=1 /path/to/directory
   ```

4. **`ncdu` (Non-Interactive Disk Usage)**:
   `ncdu` is an interactive file system usage analysis tool, which provides a more user-friendly interface for navigating through directories and files with disk usage information.

   ```sh
   sudo apt-get install ncdu  # For Debian-based systems like Ubuntu
   sudo yum install ncdu      # For Red Hat-based systems like CentOS
   ```

   After installation, you can use it as follows:

   ```sh
   sudo ncdu /path/to/directory
   ```

5. **`ncdu -r /path/to/directory`**:
   The `-r` option is used to recursively analyze the disk usage of all subdirectories and files within a specified directory.

   ```sh
   sudo ncdu -r /path/to/directory
   ```

6. **`find /path/to/directory -type f -exec du -h {} \; | sort -rh | head -n 5`**:
   This command finds all files in the specified directory and its subdirectories, sorts them by size in reverse order (largest to smallest), and then displays the top five largest files.

   ```sh
   find /path/to/directory -type f -exec du -h {} \; | sort -rh | head -n 5
   ```

These commands should help you effectively monitor disk usage on your Linux system.
