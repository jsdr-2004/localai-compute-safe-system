 Here is a simple Python function that reverses a string:

```python
def reverse_string(s):
    return s[::-1]

# Test the function
print(reverse_string("Hello World"))  # Output: dlroW olleH
```

In this example, the `[::-1]` slice notation is used to reverse the string in place. It means "start at the end of the string and end at position 0, move with the step -1", effectively reversing the order of characters in the string.
