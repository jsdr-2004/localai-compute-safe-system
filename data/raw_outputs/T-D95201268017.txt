Here are some safe and effective Linux commands to check disk usage:

### 1. Using `df` Command

The `df` command displays the disk usage information for all partitions on your system.

```bash
df -h
```

This will show you the total space used, available space, and used percentage of each partition.

### 2. Using `du` Command

The `du` command is similar to `df`, but it shows the disk usage in a more human-readable format.

```bash
du -h
```

You can also use `-s` option to get the size in bytes:

```bash
du -hs
```

### 3. Using `fsck` Command

The `fsck` command checks the file system for errors and reports any issues.

```bash
fsck -f /dev/sda1
```

Replace `/dev/sda1` with your partition device (e.g., `/dev/sda`, `/dev/sdb`, etc.).

### 4. Using `df -T` Command

The `-T` option displays the disk usage in a more detailed format, including file system type and mount point.

```bash
df -T /mnt/your_directory
```

Replace `/mnt/your_directory` with your desired mount point.

### 5. Using `fsstat` Command

The `fsstat` command provides detailed information about the disk usage for each partition.

```bash
fsstat -d /dev/sda1
```

This will show you the total space used, available space, and used percentage of each partition.

Remember to always use caution when working with file systems and partitions. Make sure to back up your data before making any changes or deleting files.
