**Reverse String Function in Python**
=====================================

Here's a simple and efficient way to reverse a string in Python:

```python
def reverse_string(s):
    """
    Reverses the input string.

    Args:
        s (str): The input string.

    Returns:
        str: The reversed string.
    """
    return s[::-1]
```

**Explanation**
---------------

This function uses Python's slice notation to extract characters from the input string, starting from the end and moving towards the beginning. The `[::-1]` syntax tells Python to start at the end of the string and move backwards to the beginning.

**Example Use Cases**
--------------------

```python
print(reverse_string("Hello World"))  # Output: "dlroW olleH"
print(reverse_string(""))  # Output: ""
```

**Note**: This function assumes that the input is a string. If you try to pass a non-string argument, it will raise an error.

Alternatively, if you want a more explicit implementation without using slice notation, here's another way to reverse a string:

```python
def reverse_string(s):
    """
    Reverses the input string.

    Args:
        s (str): The input string.

    Returns:
        str: The reversed string.
    """
    return s[::-1].replace(" ", "")  # Remove spaces from the result
```

This function adds a space back to the result if there are any extra spaces in the original string.
