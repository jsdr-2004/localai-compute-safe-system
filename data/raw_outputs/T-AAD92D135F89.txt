Certainly! Here's a simple and efficient way to create a Python function that reverses a given string:

```python
def reverse_string(s):
    return s[::-1]

# Example usage:
reversed_string = reverse_string("hello")
print(reversed_string)  # Output will be "olleh"
```

In this function, `s[::-1]` is used to slice the string. The slicing syntax in Python (`start:stop:step`) allows you to specify a step value of `-1`, which reverses the order of characters in the string.

Here's another approach using a loop for educational purposes:

```python
def reverse_string(s):
    reversed_s = ""
    for char in s:
        reversed_s = char + reversed_s  # Concatenate at the beginning to reverse the order
    return reversed_s

# Example usage:
reversed_string = reverse_string("hello")
print(reversed_string)  # Output will be "olleh"
```

In this version, we manually construct the reversed string by iterating through each character of the original string and appending it to a new string at the beginning.

Both methods are effective for reversing strings in Python. The first method using slicing is generally more efficient as it leverages Python's built-in optimizations.
