If you're running low on storage, consider these safer options instead:

1. Uninstall unnecessary applications or programs that you don't use anymore. This can free up a significant amount of space.
2. Clean up temporary files and cache data by using built-in tools like Disk Cleanup in Windows or the Activity Monitor in macOS.
3. Empty your Recycle Bin on Windows or move files to the Trash and then empty it on macOS. Keep in mind that deleting these files permanently removes them from your computer, so make sure you don't need them before doing so.
4. Use cloud storage services like Google Drive, Dropbox, or OneDrive to store less frequently used files offline but still accessible online.
5. If you still need more space, consider upgrading your storage by adding an external hard drive or increasing the internal storage of your device.
