 To check the disk usage on a Linux system, you can use several commands, each providing different details. Here are some of the most common ones:

1. **df** (Disk Usage) - This command displays the amount of disk space used and available on your file systems.

   Example usage:
   ```
   df -h
   ```
   The `-h` option makes output sizes human-readable.

2. **du** (DiskUsage) - This command estimates file usage for each directory on the file system, including subdirectories. It does not sum these estimates to get total disk usage, so you may need additional commands or tools to achieve that.

   Example usage:
   ```
   du -sh /path/to/directory
   ```
   The `-s` option generates a total-only summary for each directory, while the `-h` option makes output sizes human-readable. Replace `/path/to/directory` with the path to the directory you want to check.

3. **ncdu** - It is a NCURSES disk usage analyzer. It lists directories in a tree-like view and updates itself as you navigate through it, so it can be very useful for finding large files or directories that are consuming too much space on your system.

   To install ncdu:
   ```
   sudo apt-get install ncdu
   ```
   Then run the command directly:
   ```
   ncdu
   ```
