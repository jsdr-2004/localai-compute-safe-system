When a user runs `docker ps` and gets a "permission denied" error, it's often due to one of the following reasons:

1. **Insufficient permissions**: The user may not have the necessary permissions to access Docker resources.
2. **Incorrect group membership**: The user might be part of a group that doesn't have the required permissions to run Docker commands.
3. **Docker configuration issues**: Docker's configuration or settings might be causing the issue.

To resolve this, follow these steps:

**Step 1: Check group membership**

Run the following command to check if the user is part of any groups that have Docker-related permissions:
```bash
id -Gn <username>
```
Replace `<username>` with the actual username. This will list the groups the user belongs to.

If the user is not in a group with Docker permissions, you can add them to one of the following groups:

* `docker`: This group has read-only access to Docker containers.
* `docker-dev` or `docker-test`: These groups have read-write access to Docker containers and are suitable for development environments.
* `docker-user`: This group has full access to Docker resources, including running containers.

To add a user to one of these groups, run the following command:
```bash
sudo usermod -aG docker <username>
```
Replace `<username>` with the actual username. The `-a` flag adds the user to the specified group without logging them out.

**Step 2: Verify Docker configuration**

Check if there are any Docker configuration issues that might be causing the permission denied error:

* Run `docker info` to check for any errors or warnings.
* Check the Docker logs by running `docker logs -f`.
* Verify that the Docker socket is accessible by running `ls /var/run/docker.sock`.

**Step 3: Set up Docker user**

If you're using a Linux distribution, you can set up a Docker user with full access to Docker resources:

1. Create a new user: `sudo useradd -m -s /bin/bash dockeruser`
2. Change the ownership of Docker directories: `sudo chown -R dockeruser:docker /var/run/docker.sock` and `sudo chown -R dockeruser:docker /var/lib/docker`
3. Set up the Docker group: `sudo groupadd docker` and `sudo usermod -aG docker dockeruser`

After completing these steps, try running `docker ps` again to verify that you have the necessary permissions.

* Linux distribution
* Docker version
* Any relevant configuration files or settings
