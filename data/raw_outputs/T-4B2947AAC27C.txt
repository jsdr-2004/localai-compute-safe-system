Certainly! Below is a simple and straightforward way to create a Python function that reverses a given string using slicing:

```python
def reverse_string(s):
    """
    Reverses the input string.

    Parameters:
    s (str): The string to be reversed.

    Returns:
    str: A new string which is the reverse of the input.
    """
    return s[::-1]

# Example usage
input_str = "Hello, World!"
reversed_str = reverse_string(input_str)
print(f"Original String: {input_str}")
print(f"Reversed String: {reversed_str}")
```

In this function:
- `s` is the input string.
- The slicing syntax `[::-1]` is used to create a new string that starts from the last character and goes backwards by one step at a time, effectively reversing the order of characters.

You can test this function with different strings. Here's an example for testing:

```python
# Test cases
test_cases = ["Hello", "Python", "", "A", "12345"]

for case in test_cases:
    print(f"Original: {case} | Reversed: {reverse_string(case)}")
```

This will output the original and reversed versions of each string.
