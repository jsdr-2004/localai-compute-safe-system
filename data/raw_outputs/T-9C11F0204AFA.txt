Certainly! Here are some safe and commonly used Linux commands to check disk usage:

1. **`df -h`**:
   This command provides an overview of the available disk space in your system, with output formatted for easy reading.

2. **`du -sh /path/to/directory`**:
   Use this command to get a summary (total size) of the disk usage by files and directories under a specified directory.
   
3. **`ncdu`**:
   `ncdu` is an interactive file system usage analysis tool that provides detailed information about disk space usage in a friendly, easy-to-use interface.

4. **`lsblk`**:
   This command lists all the block devices (disks and partitions) connected to your system along with their sizes and mount points.

5. **`fdisk -l`**:
   Use this command to list all available disks and partitions on your system, showing their size and type.

6. **`parted -l`**:
   Similar to `fdisk`, the `parted -l` command lists all available disks and partitions along with their sizes and types.

7. **`du --max-depth=1 /path/to/directory | sort -hr`**:
   This command gives you a sorted list of directories under `/path/to/directory` by size, which can help identify the largest directories quickly.

8. **`ncdu /path/to/directory`** (or `ncdu /` for root directory):
   As mentioned earlier, this is an interactive tool that provides detailed information about disk space usage in a graphical interface.

These commands are safe and widely used to check disk usage effectively on Linux systems.
