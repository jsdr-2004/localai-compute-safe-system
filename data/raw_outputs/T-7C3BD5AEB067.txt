**Reversing a String in Python**
====================================

You can use the built-in `reversed` function and the `join` method to reverse a string in Python. Here is an example:

```python
def reverse_string(s):
    """
    Reverses a given string.

    Args:
        s (str): The input string to be reversed.

    Returns:
        str: The reversed string.
    """
    return "".join(reversed(s))

# Example usage:
print(reverse_string("Hello World"))  # Output: "dlroW olleH"
```

Alternatively, you can use slicing to reverse a string:

```python
def reverse_string(s):
    """
    Reverses a given string.

    Args:
        s (str): The input string to be reversed.

    Returns:
        str: The reversed string.
    """
    return s[::-1]

# Example usage:
print(reverse_string("Hello World"))  # Output: "dlroW olleH"
```

Both of these functions will produce the same result, but the slicing method is often considered more Pythonic and efficient.
