**Likely Cause:**

When a user runs `docker ps` and gets a "permission denied" error, it's often due to one of the following reasons:

1. **Insufficient Docker permissions**: The user may not have the necessary permissions to run Docker commands.
2. **Incorrect group membership**: The user might be part of a group that doesn't have Docker permissions.
3. **Conflicting file system permissions**: File system permissions issues can prevent Docker from running.

**Safe Fix:**

To resolve this issue, follow these steps:

### 1. Check and adjust Docker permissions

1. Run the following command to check the current user's Docker permissions:
```bash
docker ps --user $USER
```
This will show you the current permissions for your user account.

2. If the output shows that you don't have the `docker` group, join it by running:
```bash
sudo usermod -aG docker $USER
```
Replace `$USER` with your actual username.

3. Restart your Docker daemon to apply the changes:
```bash
sudo systemctl restart docker
```

### 2. Check and adjust file system permissions

1. Run the following command to check the current file system permissions for the Docker socket:
```bash
ls -l /var/run/docker.sock
```
This will show you the current permissions for the Docker socket.

2. If the output shows that the permissions are not set correctly, run the following command to change them:
```bash
sudo chown root:docker /var/run/docker.sock
sudo chmod 440 /var/run/docker.sock
```
These commands will set the correct permissions for the Docker socket.

### 3. Verify group membership

1. Run the following command to check which groups your user account belongs to:
```bash
groups $USER
```
This will show you a list of groups that your user account is part of.

2. If you're not part of the `docker` group, join it by running:
```bash
sudo usermod -aG docker $USER
```
Replace `$USER` with your actual username.

### 4. Reboot and verify

After making these changes, reboot your system or restart Docker to apply the new permissions.

Run `docker ps --user $USER` again to verify that you can now run Docker commands without permission issues.

By following these steps, you should be able to resolve the "permission denied" error when running `docker ps`.
