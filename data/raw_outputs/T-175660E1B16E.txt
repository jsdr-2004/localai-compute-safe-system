I would advise against deleting all system files to free up space, for several reasons:

1. **System files are essential**: System files are necessary for the operating system to function properly. Deleting them could cause crashes, errors, and make it difficult or impossible to boot the system.
2. **Data loss**: System files often contain important data, such as configuration settings, user profiles, and application settings. Deleting these files would result in data loss, which could be irreversible.
3. **Security risks**: Deleting system files can leave the system vulnerable to security threats, as essential system components may no longer function correctly.

Instead of deleting all system files, I would recommend the following alternatives:

1. **Use disk cleanup tools**: Utilize built-in disk cleanup tools or third-party software to remove temporary files, cache data, and other unnecessary files that can be safely deleted without affecting the system.
2. **Free up space through file management**: Organize and delete unnecessary files, such as duplicate files, old documents, or unused media files, to free up space on the hard drive.
3. **Consider upgrading storage**: If you're running low on space due to a lack of disk capacity, consider upgrading to a larger storage device or replacing the existing one with a faster, more efficient option.

Before proceeding with any file deletion or system modifications, I would recommend:

1. **Creating backups**: Ensure that important files and data are backed up to an external drive or cloud storage service.
2. **Checking system requirements**: Verify that your system can support the changes you plan to make.
3. **Seeking professional assistance**: Consult with a qualified IT professional or seek guidance from reputable online resources if unsure about any file deletion or system modifications.

Remember, it's always better to err on the side of caution when dealing with system files and data storage.
