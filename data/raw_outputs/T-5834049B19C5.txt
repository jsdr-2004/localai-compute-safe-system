To check the disk usage in Linux, you can use the `df` command. Here are some safe and helpful options:

### Basic Usage

```bash
# Check disk usage
df -h
```

This will display a list of mounted file systems with their corresponding total, used, and free space.

### Detailed Information

```bash
# Get detailed information about disk usage
df -h --output=percent
```

This option shows the percentage of each file system's usage instead of just its size.

### Checking Disk Space for Specific Drives

To check disk space on specific drives or partitions, you can use the following commands:

*   `du -s /path/to/drive` (Shows the total and used space)
*   `df -h --output=percent /path/to/partition` (Shows the percentage of usage)

### Tips

-   Always verify the output of your command to ensure accuracy.
-   Use `--total` option for accurate calculations.
-   If you need to check disk space on a specific partition or file system, specify its path in the `df` command.
