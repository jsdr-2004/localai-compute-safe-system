### Reversing a String in Python

You can use the built-in `reversed` function and the `join` method or the `[::-1]` slicing technique to reverse a string in Python.

#### Using `reversed` and `join`

```python
def reverse_string(s):
    """
    Returns the reversed string.
    
    Args:
        s (str): The input string.
    
    Returns:
        str: The reversed string.
    """
    return ''.join(reversed(s))
```

This function works by using the `reversed` function to generate an iterator over the characters in the string, and then joining them back into a single string using the `join` method.

#### Using Slicing

```python
def reverse_string(s):
    """
    Returns the reversed string.
    
    Args:
        s (str): The input string.
    
    Returns:
        str: The reversed string.
    """
    return s[::-1]
```

This function works by using Python's slice notation `s[start:stop:step]` to create a new string that is the reverse of the original string. By setting `start=0`, `stop=-1`, and `step=-1`, we effectively reverse the string.

### Example Use Cases

```python
print(reverse_string("hello"))  # Output: "olleh"
print(reverse_string("Python"))  # Output: "nohtyP"
```

Note that both of these functions are case-sensitive, so uppercase letters will be reversed to lowercase and vice versa. If you want a case-insensitive reversal, you can convert the string to lowercase or uppercase before reversing it:

```python
def reverse_string_case_insensitive(s):
    """
    Returns the reversed string (case-insensitive).
    
    Args:
        s (str): The input string.
    
    Returns:
        str: The reversed string (case-insensitive).
    """
    return ''.join(reversed(s.lower()))
```

You can use this function like this:

```python
print(reverse_string_case_insensitive("Hello World!"))  # Output: "!dlroW olleH"
```
