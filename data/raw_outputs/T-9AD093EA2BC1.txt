 The error "permission denied" when running `docker ps` usually indicates that the Docker daemon is running but the user does not have sufficient permissions to interact with it. Here's a safe way to fix this issue:

1. First, check if the Docker daemon is running by using the command `sudo systemctl status docker`. If it's not running, start it with `sudo systemctl start docker`.

2. To allow the current user to use Docker without sudo, you can add your user to the `docker` group. Run the following commands:

   ```
   sudo groupadd docker
   sudo usermod -aG docker $USER
   ```

   Replace `$USER` with your username if it's different from the current one. After running these commands, you need to log out and log back in for the changes to take effect.

3. To verify that the user belongs to the docker group, use the command: `id -nG`. If the output includes 'docker', then the user is part of the docker group and should be able to run Docker commands without sudo.

4. After logging back in, you can test if the issue is resolved by running `docker ps` again without using sudo. If everything went well, you should see a list of running Docker containers.
