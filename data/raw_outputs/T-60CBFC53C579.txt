When a user runs `docker ps` and gets a "Permission denied" error, it's usually due to permissions issues on the host machine or Docker daemon configuration.

Here are some possible causes and safe fixes:

**Causes:**

1. **Insufficient permissions**: The user running `docker ps` may not have the necessary permissions to access the Docker service, such as the `docker` group or the `sudo` command.
2. **Docker daemon configuration**: The Docker daemon's configuration might be set up incorrectly, preventing it from allowing the user to run commands on the container.
3. **Network issues**: A network problem, such as a firewall blocking the connection, can prevent the user from accessing the Docker service.

**Safe fixes:**

1. **Run with elevated privileges**:
   - To increase permissions, you can run `docker ps` with the `-u` flag and specify the username: `docker ps -u <username>`.
   - This will allow the container to execute as the specified user, giving it more permissions.
2. **Use Docker Compose or a container runtime**:
   - If you're running multiple containers on your host machine, consider using Docker Compose (a configuration management tool) or a container runtime like Dind (Docker Indigo Daemon) or Podman.
   - These tools can help manage the lifecycle of containers and provide more fine-grained control over permissions and access.
3. **Disable firewall rules**:
   - If you're using a firewall to block incoming connections, consider disabling it temporarily while running `docker ps`.
   - Be cautious when disabling firewalls, as this can expose your system to unauthorized access.
4. **Check Docker daemon logs**:
   - You can run `docker logs -f` to check the Docker daemon's log files for any error messages related to permissions or configuration issues.
5. **Verify Docker service configuration**:
   - Check the Docker service configuration file (usually `/etc/docker/daemon.json`) to ensure it's set up correctly.
   - Make sure the `authToken` and `registry` configurations are valid.

By following these steps, you should be able to resolve the "Permission denied" error when running `docker ps`.
