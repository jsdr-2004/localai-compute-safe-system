Certainly! Below is a simple and efficient Python function that reverses a given string:

```python
def reverse_string(input_string):
    """
    Reverses the input string.

    Parameters:
        input_string (str): The string to be reversed.

    Returns:
        str: The reversed string.
    """
    return input_string[::-1]

# Example usage:
original_string = "Hello, World!"
reversed_string = reverse_string(original_string)
print(f"Original String: {original_string}")
print(f"Reversed String: {reversed_string}")
```

This function uses Python's slicing feature to create a reversed version of the input string. The `[::-1]` slice notation is particularly efficient and readable for reversing strings.
