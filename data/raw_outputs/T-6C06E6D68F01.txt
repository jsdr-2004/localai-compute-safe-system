Certainly! Below is a simple and straightforward Python function that takes a string as an argument and returns the reversed version of it.

```python
def reverse_string(s):
    """
    Reverses the given input string s.
    
    Parameters:
        s (str): The string to be reversed.

    Returns:
        str: The reversed string.
    """
    return s[::-1]

# Example usage:
input_str = "hello"
reversed_str = reverse_string(input_str)
print(f"Original String: {input_str}")
print(f"Reversed String: {reversed_str}")
```

In this function, `s[::-1]` uses Python's slicing feature to create a reversed copy of the string. The slice notation `[start:stop:step]` is used here with `start=None`, `stop=len(s)`, and `step=-1`, which effectively reverses the string.

You can also use the more traditional loop method for educational purposes:

```python
def reverse_string_loop(s):
    """
    Reverses the given input string s by iterating through it.
    
    Parameters:
        s (str): The string to be reversed.

    Returns:
        str: The reversed string.
    """
    reversed_str = ""
    for char in s:
        reversed_str = char + reversed_str
    return reversed_str

# Example usage:
input_str = "hello"
reversed_str = reverse_string_loop(input_str)
print(f"Original String: {input_str}")
print(f"Reversed String: {reversed_str}")
```

In this loop method, we initialize an empty string `reversed_str` and then iterate over each character in the input string. For each character, we prepend it to the `reversed_str`, effectively building up the reversed version of the string.

Both methods are correct; the choice between them depends on your preference or specific requirements.
