 Sure, here's a simple Python function that reverses a string:

```python
def reverse_string(input_string):
    return input_string[::-1]
```

In this function, `[::-1]` is a slice notation in Python that reverses the order of elements in a sequence (like strings or lists). The `reverse_string` function takes an input string and returns the reversed version of it.

You can use this function like so:

```python
print(reverse_string("Hello, World!"))  # Outputs: !dlroW ,olleH
```
