Here are some safe Linux commands to check disk usage:

1. **df** (Disk Free) command:
   ```bash
df -h
```
   This command displays the amount of free space on each partition, including file systems mounted on the system.

2. **du** (Disk Usage) command:
   ```bash
du -sh /
```
   This command displays the total size of all files and directories in the root directory (`/`).

3. **fsck** (File System Check) command:
   ```bash
fsck -n /dev/sda1
```
   This command checks the file system on the specified partition without making any changes.

4. **df -i** command:
   ```bash
df -i
```
   This command displays information about disk usage, including the number of inodes used and available.

5. **du -d 1 -h / | grep total** command:
   ```bash
du -d 1 -h /
| grep total
```
   This command recursively calculates the total size of all files and directories in the root directory (`/`) and displays only the total size.

Remember to always use caution when running commands that affect your system's file systems, as they can potentially cause data loss or corruption.
