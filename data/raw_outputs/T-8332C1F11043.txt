Here are some safe Linux commands to check disk usage:

### 1. Using `df` command

The `df` command displays the disk usage information for the currently running processes.

```bash
df -h
```

This will show you the disk usage in a human-readable format, with columns for `/`, `total`, `used`, `available`, and `use%`.

### 2. Using `du` command

The `du` command is similar to `df`, but it displays the disk usage in bytes.

```bash
du -h
```

This will show you the disk usage in a human-readable format, with columns for `/`, `total`, `used`, and `available`.

### 3. Using `fsck` command

The `fsck` command checks the file system for errors or inconsistencies on the given disk.

```bash
fsck -t ext4 /dev/sdb1
```

Replace `/dev/sdb1` with the device path of your desired disk. This will check if there are any errors in the file system and fix them if necessary.

### 4. Using `losetup` command

The `losetup` command is used to create a loopback device on an existing disk, allowing you to mount it as a separate partition.

```bash
losetup /dev/sda1
```

Replace `/dev/sda1` with the device path of your desired disk. This will create a loopback device on that disk and allow you to mount it as a separate partition.

### 5. Using `mount` command

The `mount` command is used to mount or unmount file systems on a Linux system.

```bash
sudo mount /dev/sda1 /mnt
```

Replace `/dev/sda1` with the device path of your desired disk, and `/mnt` with the directory where you want to mount it. This will mount the entire disk as a separate partition on the `/mnt` directory.

### 6. Using `top` command

The `top` command displays a list of running processes and their resource usage in real-time.

```bash
top -h
```

This will show you which processes are using the most resources, allowing you to identify potential bottlenecks on your system.

These commands are all safe and easy to use, and they can help you monitor disk usage and optimize your system performance.
