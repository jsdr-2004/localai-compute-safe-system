Here are some safe Linux commands to check disk usage:

1. **`df -h`**: This command displays the current disk usage, including the amount of used and available space, for each file system on your system. The `-h` option stands for "human-readable" and displays the values in a more user-friendly format.

Example:
```
$ df -h
Filesystem      Size  Used   Avail  Use% Mounted on
/dev/sda1      931G  234G   696G   25% /
```

2. **`du -sh /`**: This command estimates the total disk usage of your root directory and its contents. The `-s` option stands for "summarize" and displays the total size, while `-h` stands for "human-readable".

Example:
```
$ du -sh /
122G    .
```

3. **`lsblk -o SIZE,FREE,USED /dev/sda1`**: This command displays detailed information about the disk usage of a specific device (in this case `/dev/sda1`). The `-o` option stands for "output" and specifies the columns to display.

Example:
```
$ lsblk -o SIZE,FREE,USED /dev/sda1
SIZE  FREE     USED   FILESYSTEM TYPE      LSIZE  MOUNTPOINT
931G    696G   234G             ext4         931G    /
```

4. **`sudo disk usage` (on some distributions)**: Some Linux distributions, like Ubuntu and Debian, have a built-in command called `disk usage` that displays the current disk usage.

Example:
```
$ sudo disk usage
Total   Used   Free   Part Used    Mountpoint
 931G    234G   696G      25%     /
```

Remember to use these commands with caution and in a controlled environment, as excessive disk usage can lead to performance issues or even system crashes.
