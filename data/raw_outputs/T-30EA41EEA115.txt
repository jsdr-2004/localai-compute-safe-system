Certainly! Here are some safe and effective Linux commands that you can use to check the disk usage of your system:

1. **`df -h`**
   - This command is used to display disk space in a human-readable format (e.g., MB, GB). The `-h` option makes it more readable.
   - Example:
     ```
     df -h
     ```

2. **`du -sh /path/to/directory`**
   - Use this command to get the summary of space used by a directory and its contents.
   - Replace `/path/to/directory` with the directory you want to check.
   - Example:
     ```
     du -sh /var
     ```

3. **`ncdu` (Non-interactive Disk Usage Analysis Tool)**
   - This is an interactive tool that allows you to navigate through directories and provides detailed information about disk usage in a visually appealing way.
   - Installation: If `ncdu` is not installed, you can install it using:
     ```bash
     sudo apt-get install ncdu  # For Debian-based systems
     sudo yum install ncdu        # For Red Hat/CentOS system
     ```
   - Usage:
     ```
     ncdu /path/to/directory
     ```

4. **`ncursesdu` (A curses interface for `du`)**
   - Another interactive tool to analyze disk usage similar to `ncdu`. It is available through package managers.
   - Installation: 
     ```bash
     sudo apt-get install ncdu  # For Debian-based systems
     ```

5. **`inotify-tools` (For monitoring changes in file system)**
   - This command-line tool can be used to monitor a directory for changes which might help identify the source of excessive disk usage.
   - Example:
     ```
     inotifywait -m /path/to/directory --format "%w%f %T" | sort
     ```

6. **`lsof +Fsu`**
   - This command lists all files that are currently opened by processes, which can help identify large files or directories causing excessive disk usage.
   - Example:
     ```
     lsof +Fsu /path/to/directory
     ```

These commands will give you a good overview of your system's disk space utilization and allow you to focus on problematic areas. If you need more specific information, such as per file type or user-based usage analysis, these tools can be combined with other commands for even deeper insights.
