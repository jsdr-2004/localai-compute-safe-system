Here are some safe and effective Linux commands to check disk usage:

1. **`df -k`**: This command displays detailed information about the mounted file systems, including their usage statistics.
   ```
   df -k /path/to/your/disk
   ```

2. **`du -s`**: This command displays the total size of all files and directories on a specific disk in bytes.
   ```
   du -s /path/to/your/disk
   ```

3. **`fsck -f`**: This command checks for and repairs any errors on the file system.
   ```
   fsck -f /path/to/your/disk
   ```

4. **`lsblk`**: This command displays information about all block devices (disks) on your system, including their usage statistics.
   ```
   lsblk
   ```

5. **`df -h`**: This command provides a brief summary of disk usage in human-readable format.
   ```
   df -h /path/to/your/disk
   ```

6. **`mounts`**: This command displays information about all mounted file systems on your system, including their usage statistics.
   ```
   mounts
   ```

7. **`du -r`**: This command displays the total size of all files and directories in a specific directory tree.
   ```
   du -r /path/to/your/directory
   ```

8. **`df -P`**: This command provides a more detailed view of disk usage, including information about file systems and their corresponding mount points.
   ```
   df -P /path/to/your/disk
   ```
