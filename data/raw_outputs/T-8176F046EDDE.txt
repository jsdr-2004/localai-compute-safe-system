Here are some safe and effective Linux commands to check disk usage:

### 1. Using `df` command

The `df` command displays the disk usage information, including the total size of each partition or file system.

```bash
df -h
```

This will display the disk usage in a human-readable format, showing the percentage of used space on each partition.

### 2. Using `du` command

The `du` command is similar to `df`, but it displays the disk usage information in kilobytes (KB), megabytes (MB), gigabytes (GB), or terabytes (TB).

```bash
du -h
```

This will display the disk usage information in a human-readable format, showing the percentage of used space on each partition.

### 3. Using `fsck` command

The `fsck` command is used to check and repair file systems that are damaged or corrupted.

```bash
fsck -f /dev/sda1
```

This will scan the `/dev/sda1` disk (assuming it's the root partition) for errors and report any issues. If there are any problems, `fsck` will attempt to fix them.

### 4. Using `mount` command

The `mount` command is used to check and manage file systems on your Linux system.

```bash
mount | grep /dev/sda1
```

This will display information about the `/dev/sda1` partition, including its mount point, filesystem type, and usage statistics.

### 5. Using `df -T` command

The `df -T` command is similar to `df`, but it displays more detailed disk usage information, including the file system type and usage statistics.

```bash
df -T /dev/sda1
```

This will display the disk usage information for the `/dev/sda1` partition in a more detailed format.

### 6. Using `du -s` command

The `du -s` command is similar to `du`, but it displays the disk usage information in seconds (s), rather than kilobytes (KB).

```bash
du -s /dev/sda1
```

This will display the disk usage information for the `/dev/sda1` partition in seconds.

Remember to always use caution when checking disk usage, as incorrect commands or options can cause system instability.
