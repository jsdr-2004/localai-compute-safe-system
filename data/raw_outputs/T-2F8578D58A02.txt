When a user runs `docker ps` and gets a "permission denied" error, it's often due to one of the following reasons:

1. **Insufficient permissions**: The user may not have the necessary permissions to access Docker resources.
2. **Incorrect group membership**: The user might be part of a group that doesn't have the required permissions to run Docker commands.
3. **Docker socket issue**: The Docker socket might not be accessible due to permission issues or incorrect configuration.

To resolve this issue, follow these steps:

**1. Check group membership**

Run `groups` command to check which groups the user belongs to:
```bash
$ groups
user1  docker
```
If the user is part of the `docker` group, ensure that the group has the necessary permissions to run Docker commands.

**2. Verify Docker socket permissions**

Check the permissions on the Docker socket file (`/var/run/docker.sock`):
```bash
$ ls -l /var/run/docker.sock
```
The output should show the owner and group of the file:
```
-rw-r--r-- 1 root docker 0 Dec 12 14:30 /var/run/docker.sock
```
If the user is not the owner or part of the `docker` group, you may need to adjust the permissions.

**3. Adjust Docker socket permissions**

To allow the user to access the Docker socket, you can modify the permissions:
```bash
$ sudo chown -R $USER:$GROUP /var/run/docker.sock
```
Replace `$USER` and `$GROUP` with the actual username and group name of the user.

Alternatively, you can add the user to the `docker` group and adjust the permissions accordingly:
```bash
$ sudo usermod -aG docker $USER
```
**4. Restart Docker**

After making changes to the Docker socket permissions or adjusting group membership, restart the Docker service:
```bash
$ sudo systemctl restart docker
```
**5. Verify permissions**

Run `docker ps` again to verify that you can access it without any permission issues.

If none of these steps resolve the issue, you may need to investigate further and adjust your system configuration or seek additional assistance from a system administrator or Docker expert.
