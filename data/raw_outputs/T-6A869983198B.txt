Here are some safe Linux commands to check disk usage:

1. **`df -h`**: Displays a list of all file systems, showing the amount of used and available space in human-readable format.

2. **`du -sh /`**: Displays the total size of all files and directories on the root partition, showing the amount of used and free space.

3. **`fsck -n /`**: Checks the file system on the root partition for errors without making any changes.

4. **`sudo fsck -N /`**: Checks the file system on the root partition for errors and makes a note of any problems found, but does not fix them.

5. **`sudo fsck -F ext4 /`**: Checks the file system on the root partition for errors using the ext4 file system type.

6. **`sudo e4defrag /`**: Defragments the file system on the root partition to improve performance.

7. **`sudo fstrim -d /`**: Trims unused space from the file system on the root partition to free up disk space.

8. **`sudo fstrim -r /`**: Trims used space from the file system on the root partition to reduce fragmentation.

9. **`sudo du -h --max-depth=1 /`**: Displays the total size of all files and directories in the current directory, showing the amount of used and free space.

10. **`sudo du -sh --max-depth=1 /var/log/`**: Displays the total size of all log files in the `/var/log/` directory, showing the amount of used and free space.

Remember to always use `sudo` with caution and only when necessary, as it can potentially allow unauthorized access to your system.
