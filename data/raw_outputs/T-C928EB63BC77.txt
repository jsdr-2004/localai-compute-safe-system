To check the disk usage on a Linux system, you can use several safe and useful commands. Here are some of them:

1. **df (Disk Free)**
   - This command gives information about file system space usage.
   ```bash
   df -h
   ```
   The `-h` option makes it easier to read by using human-readable formats.

2. **du (Disk Usage)**
   - This command shows disk usage of directories and files in a tree-like structure.
   ```bash
   du -ah /path/to/directory
   ```
   Use the `-a` flag for detailed information, including hidden files, and the `-h` flag to display sizes in human-readable format.

3. **ncdu (NCurses Disk Usage)** 
   - This is a user-friendly disk usage analyzer based on `du`.
   ```bash
   ncdu /path/to/directory
   ```
   It uses an interactive menu-driven interface that allows you to navigate through directories and see their sizes.

4. **find**
   - This command can be used to find files in the system.
   ```bash
   find /path/to/search -type f -print0 | xargs -0 du -chs *
   ```
   You can also use this to get an overview of disk usage with more fine-grained control over file types and paths.

5. **lsblk**
   - This command lists all the block devices and their mount points.
   ```bash
   lsblk
   ```

6. **parted**
   - If you need detailed information about partition sizes, `parted` can provide it.
   ```bash
   sudo parted /dev/sdX print
   ```
   Replace `/dev/sdX` with the appropriate device.

7. **ncurses-capable dusage (from util-linux package)**
   - Utilizing the `-p` option, you can see detailed disk usage information in a curses-based interface.
   ```bash
   dusage /path/to/directory -p
   ```

These commands will help you understand where your storage is being used and how much space each directory or file occupies.
