 Here is a simple Python function that reverses a string:

```python
def reverse_string(input_str):
    return input_str[::-1]

# Test the function
print(reverse_string("Hello, World!"))  # Output: !dlroW ,olleH
```

In this example, the `[::-1]` slice notation is used to reverse the string. This notation means "start at the end of the string and move backwards with a step size of -1".
