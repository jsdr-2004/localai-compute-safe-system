 Sure, here's a simple Python function that reverses a given string:

```python
def reverse_string(input_str):
    return input_str[::-1]

# Test the function
print(reverse_string("Hello World"))  # Output: dlroW olleH
```

In this function, `[::-1]` is a slice that reverses the order of elements in the string. The `input_str` argument is the string to be reversed.
