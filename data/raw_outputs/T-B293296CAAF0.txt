Certainly! Below is a simple and efficient way to write a Python function that reverses a given string:

```python
def reverse_string(s):
    """
    Reverses the input string.

    Parameters:
        s (str): The string to be reversed.

    Returns:
        str: The reversed string.
    """
    return s[::-1]

# Example usage:
original_string = "hello"
reversed_string = reverse_string(original_string)
print(reversed_string)  # Output will be "olleh"
```

This function uses Python's slicing feature, which is both concise and efficient. The `s[::-1]` syntax creates a new string that starts from the end of `s` and moves backwards by one character at a time.

If you want to reverse the string in-place (modifying the original string), you can use the following approach:

```python
def reverse_string_in_place(s):
    """
    Reverses the input string in place.

    Parameters:
        s (str): The string to be reversed.

    Returns:
        None: This function does not return anything. It modifies the input string.
    """
    # Using Python's slicing and swapping method for in-place reversal
    s[:] = s[::-1]

# Example usage:
original_string = "hello"
reverse_string_in_place(original_string)
print(original_string)  # Output will be "olleh"
```

In this version, `s[:] = s[::-1]` creates a temporary list from the reversed string and then replaces the original string with it. This is efficient because Python strings are immutable, so in-place modifications involve creating a new string object.

Both methods achieve the same goal of reversing the input string, but the second method (`reverse_string_in_place`) modifies the original string directly if you need to preserve the original state.
