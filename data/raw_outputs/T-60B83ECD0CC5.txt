**Reversing a String in Python**
=====================================

Here is a simple and efficient way to reverse a string in Python:

```python
def reverse_string(s):
    """
    Reverses the input string.

    Args:
        s (str): The input string to be reversed.

    Returns:
        str: The reversed string.
    """
    return s[::-1]
```

**Explanation**
---------------

This function uses Python's slice notation `s[start:stop:step]` to reverse the string. Here's how it works:

*   `start`: The starting index of the slice (default is 0).
*   `stop`: The ending index of the slice (default is the length of the string).
*   `step`: The increment between indices (default is 1).

By setting `step` to `-1`, we're telling Python to start from the end of the string and move backwards, effectively reversing it.

**Example Use Cases**
---------------------

```python
print(reverse_string("hello"))  # Output: "olleh"
print(reverse_string("Python"))  # Output: "nohtyP"
```

You can also use this function with a list or other iterable to reverse its contents:

```python
fruits = ["apple", "banana", "cherry"]
reversed_fruits = [reverse_string(f) for f in fruits]
print(reversed_fruits)  # Output: ["cherry", "banana", "apple"]
```

This is a concise and readable way to reverse strings in Python.
