Here are some safe and effective Linux commands to check disk usage:

### 1. Using `df` command

The `df` command is a built-in utility that displays the storage usage of your system.

```bash
df -h
```

This will show you the total, used, and free space on each partition or file system.

### 2. Using `du` command

The `du` command is similar to `df`, but it shows only the disk usage in terms of bytes.

```bash
du -h
```

You can also use `-s` option to show the disk usage in terms of percentage.

```bash
du -hs /path/to/directory
```

### 3. Using `fsck` command

The `fsck` command is used to check and repair file systems, but it also displays disk usage information.

```bash
fsck -f /path/to/directory
```

This will show you the status of your file system, including disk usage.

### 4. Using `mount` command

The `mount` command is used to display information about mounted file systems.

```bash
mount | grep "Usage"
```

This will show you the current disk usage for each mounted file system.

### 5. Using `lsblk` and `df` commands with `-F` option

You can use the `lsblk` command to list all block devices (disks) on your system, and then use the `df` command with the `-F` option to display disk usage information for each device.

```bash
lsblk -o FSTYPE,LABEL,MOUNTPOINT,SIZE,USE,AVAIL,USED,PERCENT | df -h
```

This will show you the disk usage information for each block device on your system.
