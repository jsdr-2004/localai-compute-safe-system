You can use the `systemctl` command to inspect a systemd service without modifying it.

Here are some common commands you can use:

1. **List all services**: `systemctl list-units --type=service`

   This will show you a list of all services that are currently running or pending, including their status and description.

2. **Show details of a specific service**: `systemctl show <service_name>`

   Replace `<service_name>` with the name of the service you want to inspect. This command will display detailed information about the service, such as its configuration file, dependencies, and execution environment.

3. **Check if a service is enabled or disabled**: `systemctl is-enabled <service_name>`

   This command will tell you whether the service is currently enabled (i.e., running) or disabled (i.e., not running).

4. **Start or stop a service**: `systemctl start/stop <service_name>`

   Replace `<service_name>` with the name of the service you want to start or stop.

5. **Restart a service**: `systemctl restart <service_name>`

   This command will immediately stop and then restart the service.

6. **Check if a service is running**: `systemctl status <service_name>`

   This command will show you whether the service is currently running, and what its current state is.

7. **Show dependencies of a service**: `systemctl show --property=Dependencies <service_name>`

   Replace `<service_name>` with the name of the service you want to inspect. This command will display the services that this service depends on.

8. **Check if a service has any active or inactive units**: `systemctl list-units --type=unit --state=active/inactive`

   This command will show you all units (including services) that are currently running, stopped, or inactive.

These commands can help you understand how your systemd service is configured and behave without modifying the service itself.
