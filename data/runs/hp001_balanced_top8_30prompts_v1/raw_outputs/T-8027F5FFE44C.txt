Inspecting a systemd service without making any changes involves using the `systemctl` command and examining its output. Here's how you can do that:

1. **List all services:**
   You can list all available services with their current status (running, stopped, etc.) by running:
   ```sh
   sudo systemctl list-unit-files --type=service
   ```
   This will show a table of all service files in the system along with their current status.

2. **Inspect specific service:**
   To inspect details about a specific service, you can use `systemctl` to get detailed information:
   ```sh
   sudo systemctl list-units --type=service --all --state=[RUNNING|STOPPED|RELOADING|ACTIVE|BLOCKED|TRANSIENT]
   ```
   Replace `[RUNNING|STOPPED|RELOADING|ACTIVE|BLOCKED|TRANSIENT]` with the desired state. For example, to see all services in the `active (running)` state:
   ```sh
   sudo systemctl list-units --type=service --all --state=active
   ```

3. **Inspect a service's configuration:**
   You can view the current configuration of a specific service by using:
   ```sh
   sudo systemctl show -p ALL [SERVICE_NAME]
   ```
   Replace `[SERVICE_NAME]` with the name of your service (e.g., `httpd`, `nginx`, etc.). This will display all properties and values for that service.

4. **Inspect logs:**
   To inspect logs related to a specific service, you can use:
   ```sh
   sudo journalctl -u [SERVICE_NAME]
   ```
   Replace `[SERVICE_NAME]` with the name of your service (e.g., `httpd`, `nginx`, etc.). This will show all log entries for that service.

5. **Inspect dependencies:**
   You can check which services depend on a specific service by using:
   ```sh
   sudo systemctl list-dependencies [SERVICE_NAME]
   ```
   Replace `[SERVICE_NAME]` with the name of your service (e.g., `httpd`, `nginx`, etc.). This will show all dependencies for that service.
