 The error "permission denied" when running the `docker ps` command typically occurs because Docker is not run as a root user or the current user does not have sufficient permissions to interact with the Docker daemon. Here are some steps to troubleshoot and resolve the issue:

1. Check if Docker is installed and running:
   ```
   docker --version
   systemctl status docker
   ```

2. Verify that the current user has access to the Docker daemon:
   ```
   sudo ls -l /var/run/docker.sock
   ```
   This should show a file owned by root and group `docker`. If not, you might need to add your user to the `docker` group:

   ```
   sudo usermod -aG docker $USER
   ```
   After adding the user, log out and log back in so that the group membership is reloaded.

3. Check if the Docker daemon is configured to listen on Unix socket:
   Open /etc/docker/daemon.json and ensure the following configuration:
   ```
   {
       "hosts": ["unix:///var/run/docker.sock"],
       "iptables": false,
       "log-driver": "json-file",
       "log-opts": {"max-size": "10m","max-file": "3"}
   }
   ```
   Save the file and restart Docker:
   ```
   systemctl daemon-reload
   systemctl restart docker
   ```
4. Test if the user can access the Docker daemon:
   ```
   docker ps --unix-socket /var/run/docker.sock
   ```
   If the command works, then you have successfully granted your current user permission to interact with the Docker daemon.
