 An off-by-one error in Python (or any programming language) occurs when an index or counter goes beyond the expected range, causing unexpected behavior. Here's an example of a simple off-by-one error in Python:

```python
def print_list(lst):
    for i in range(len(lst)):
        print(lst[i])

# Example list
my_list = [1, 2, 3, 4]
print_list(my_list)
```

Output:

```
1
2
3
4
IndexError: string index out of range
```

The function `print_list()` has an off-by-one error because it iterates up to (but not including) the length of the list, which causes an `IndexError` when trying to access `lst[len(lst)]`. To fix this issue, we can modify the loop condition:

```python
def print_list(lst):
    for i in range(len(lst)):
        print(lst[i])
    print()  # Added a newline to separate each list output

my_list = [1, 2, 3, 4]
print_list(my_list)
```

Now the function correctly prints the list and does not throw an error:

Output:

```
1
2
3
4
```
