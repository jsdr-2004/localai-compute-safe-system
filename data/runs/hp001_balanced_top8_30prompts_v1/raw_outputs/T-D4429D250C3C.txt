```python
def safe_parse_ints(string_list):
    """
    Parses a list of strings and returns a list of integers.
    
    Parameters:
        string_list (list): A list of strings that are expected to represent integers.
        
    Returns:
        list: A list of integers extracted from the input list of strings. If any string cannot be parsed as an integer, it is skipped.
    """
    # Initialize an empty list to store the parsed integers
    int_list = []
    
    for item in string_list:
        try:
            # Attempt to convert the string to an integer
            num = int(item)
            # Append the integer to the list if conversion was successful
            int_list.append(num)
        except ValueError:
            # If conversion fails, skip this item and continue with the next one
            continue
    
    return int_list

# Example usage:
string_list = ["123", "456", "789", "not_a_number"]
parsed_ints = safe_parse_ints(string_list)
print(parsed_ints)  # Output: [123, 456, 789]
```

In this function:

- We initialize an empty list `int_list` to store the integers that can be parsed.
- For each string in the input list:
  - We attempt to convert it to an integer using `int(item)`.
  - If successful (i.e., no `ValueError` is raised), we append the converted integer to `int_list`.
  - If a conversion fails, a `ValueError` exception is caught and ignored (`continue` statement).
- Finally, we return the list of parsed integers.

This function handles cases where some strings in the input list cannot be successfully parsed as integers by skipping them.
