Here's a step-by-step guide to installing and verifying Docker on Ubuntu:

**Step 1: Update the Package Index**

Open your terminal and update the package index to ensure you have access to the latest packages:
```bash
sudo apt update
```
This command updates the package index, which includes all available packages in the repository.

**Step 2: Install Docker**

Install Docker using the following command:
```bash
sudo apt install docker.io
```
This command installs the `docker.io` package, which includes the Docker engine and its dependencies.

**Step 3: Start and Enable Docker**

Start the Docker service and enable it to start automatically on boot:
```bash
sudo systemctl start docker
sudo systemctl enable docker
```
These commands start the Docker service and ensure that it will start automatically when you reboot your system.

**Step 4: Verify Docker Installation**

Verify that Docker is installed correctly by running the following command:
```bash
docker --version
```
This command displays the version of Docker installed on your system.

You can also verify that Docker is working by running a simple container, such as `hello-world`:
```bash
docker run hello-world
```
If everything is installed correctly, you should see a message indicating that Docker has finished setting up and is ready to use.

**Step 5: Verify Container Creation**

Create a new directory and navigate to it in your terminal:
```bash
mkdir my-container
cd my-container
```
Create a `Dockerfile` in the directory with the following contents:
```dockerfile
FROM ubuntu:latest

RUN echo "Hello, World!"
```
This Dockerfile creates a new container based on the `ubuntu:latest` image and runs the command `echo "Hello, World!"`.

Build the Docker image by running the following command:
```bash
docker build -t my-container .
```
This command builds the Docker image with the name `my-container`.

Verify that the container was created successfully by running the following command:
```bash
docker run my-container
```
You should see a message indicating that a new container has been created and is running.

That's it! You have successfully installed and verified Docker on Ubuntu.
