Inspecting a systemd service without making any changes involves using the `systemctl` command-line tool, which is part of the systemd package and used for managing system services in Linux systems.

Here's a step-by-step guide on how to inspect a specific systemd service:

1. **List all active services:**
   You can list all currently active (running or failed) services using:
   ```sh
   systemctl list-units --type=service --state=active | grep -v 'loaded\.pruned'
   ```
   This command will show you the name and status of all active services.

2. **Inspect a specific service:**
   To inspect details about a specific service, use the `systemctl` command with the `-p` option to specify which properties you want to see:
   ```sh
   systemctl list-units --type=service --state=all | grep <SERVICE_NAME>
   ```
   Replace `<SERVICE_NAME>` with the name of the service you're interested in. For example, if you are inspecting a service named `httpd`, you would use:
   ```sh
   systemctl list-units --type=service --state=all | grep httpd
   ```

3. **Inspect detailed information about a specific service:**
   To get more detailed information about the service, including its configuration file and current status, you can use:
   ```sh
   systemctl show <SERVICE_NAME>
   ```
   Again, replace `<SERVICE_NAME>` with the name of your service.

4. **View the unit file for a specific service:**
   You can view the actual systemd unit file (which contains all configuration settings) using:
   ```sh
   systemctl show --property=UnitFile --value <SERVICE_NAME>
   ```
   This will display the unit file path, which you can then use to inspect or modify the configuration.

5. **Inspect service status and logs:**
   To see the current status of a specific service (whether it is running, failed, etc.), you can use:
   ```sh
   systemctl status <SERVICE_NAME>
   ```
   For detailed logs related to the service, you can use:
   ```sh
   journalctl -u <SERVICE_NAME> --since "1 hour ago"
   ```
