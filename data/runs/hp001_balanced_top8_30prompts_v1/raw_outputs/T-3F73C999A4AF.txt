To inspect memory and CPU load on a Linux system, you can use the following read-only commands:

**Memory (RAM) Inspection**

1. `top -bn1 mem`: This command displays the current memory usage of each process in real-time, with the time interval set to 1 second.
2. `htop -p <pid>`: Replace `<pid>` with the process ID you want to inspect. This command displays detailed information about the process, including its memory usage.
3. `ps aux | grep mem`: This command lists all processes and their memory usage in a table format.

**CPU Load Inspection**

1. `top -bn 1 cpu`: This command displays the current CPU load of each process in real-time, with the time interval set to 1 second.
2. `htop -p <pid>`: Replace `<pid>` with the process ID you want to inspect. This command displays detailed information about the process, including its CPU usage.
3. `ps aux | grep cpu`: This command lists all processes and their CPU usage in a table format.

**Example Use Cases**

* To get an overview of memory usage across multiple processes: `top -bn1 mem > /tmp/memory_usage.log`
* To analyze CPU load on specific processes: `htop -p <pid> > /tmp/cpu_load.log`
* To monitor memory and CPU load over time: `while true; do top -bn 1 mem; sleep 1; done` (this command will run indefinitely, displaying the current memory usage every second)
