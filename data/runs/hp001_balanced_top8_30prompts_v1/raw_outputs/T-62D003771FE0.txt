Here are some read-only Linux commands to inspect memory and CPU load:

**Memory Inspection**

1. `cat /proc/meminfo`: Displays information about the system's memory, including total, available, used, and cached memory.
2. `free -m`: Displays a summary of the system's memory usage in megabytes (MB).
3. `dmidecode -s mem-buffered | grep Buffers`: Displays the number of buffered pages.

**CPU Load Inspection**

1. `top`: Displays real-time information about the system's CPU utilization, including processes and their respective CPU usage.
2. `htop`: Similar to top, but provides more interactive and user-friendly interface.
3. `mpstat -1`: Displays CPU statistics for the last second.
4. `vmstat -n 1 | grep cpu`: Displays the number of CPU context switches per second.
5. `cat /proc/stat`: Displays a snapshot of system statistics, including CPU usage.

**Other Useful Commands**

1. `sar -q`: Displays real-time I/O statistics for disk and network devices.
2. `sysdig`: A command-line tool that provides detailed information about system performance and resource usage.
3. `perf stat`: Measures the performance of a specific process or the entire system, providing detailed information about CPU, memory, and other metrics.

Note: These commands are read-only, meaning they do not modify any data on disk but rather display information that is already stored in the system's memory or configuration files.
