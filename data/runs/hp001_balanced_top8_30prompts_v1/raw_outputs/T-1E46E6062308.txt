 Here's a Python function that uses the built-in `try/except` block to parse integers safely from a list of strings:

```python
def safe_parse_integers(lst):
    parsed_ints = []
    for item in lst:
        try:
            parsed_ints.append(int(item))
        except ValueError:
            # If the conversion fails (e.g., due to non-numeric input), skip the item and continue with the next one.
            pass
    return parsed_ints
```

You can use this function like so:

```python
lst = ['1', '2.5', '3', 'four', '5']
parsed_ints = safe_parse_integers(lst)
print(parsed_ints)  # Output: [1, 3, 5]
```

In the example above, the function safely parses integers from a list containing both numeric and non-numeric strings. The resulting `parsed_ints` list only contains the integers found in the original list (in this case, 1, 3, and 5).
