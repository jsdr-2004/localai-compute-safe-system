To inspect memory and CPU load on a Linux system, you can use the following read-only commands:

**Memory Inspection**

1. `free -m`: Displays a list of currently running processes with their memory usage.
2. `top -b -n 1 -p <pid>`: Displays the current process ID (PID) and its memory usage in real-time.
3. `ps -eo pid,comm,etimes,mem` or `ps -o pid,comm,etimes,mem`: Displays a list of running processes with their PID, command name, execution time, and memory usage.

**CPU Load Inspection**

1. `top -b -n 1 -p <pid>`: Displays the current process ID (PID) and its CPU usage in real-time.
2. `htop` or `top -H`: Displays a graphical interface to view CPU usage and other system information.
3. `iostat -d <device>`: Displays disk I/O statistics, including CPU load.
4. `sysdig -c cpu` or `sysdig -c io`: Displays CPU and I/O statistics.

**Example Use Cases**

* To get a list of running processes with their memory usage:
```bash
free -m | grep Mem
```
* To display the current process ID (PID) and its CPU usage in real-time:
```bash
top -b -n 1 -p <pid>
```
* To view disk I/O statistics, including CPU load:
```bash
iostat -d /dev/sda1
```
Note: The `free` command is used to display memory information. The `-m` option displays the memory usage in megabytes (MB).
