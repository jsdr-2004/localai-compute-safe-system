Here are some read-only Linux commands to inspect disk usage:

1. **df** (Disk Free) - Displays the amount of free space on each file system.
   ```
   df -h
   ```

2. **du** (Disk Usage) - Estimates the size of files and directories, including their subdirectories.
   ```
   du -sh /
   ```

3. **lsblk** or **fdisk** - Displays information about disk partitions.
   ```
   lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
   ```

4. **df -i** (Disk Free with Inodes) - Displays the number of inodes used and available on each file system.
   ```
   df -ih
   ```

5. **du -h --max-depth=1 / | grep total** - Estimates the size of files and directories, including their subdirectories, up to a maximum depth of 1.
   ```
   du -h --max-depth=1 /
   ```

6. **df -k** (Disk Free with Kilobytes) - Displays disk usage in kilobytes instead of megabytes or gigabytes.
   ```
   df -kh
   ```

7. **ls -lh** (Long Format) - Displays detailed information about files and directories, including their size.
   ```
   ls -lh /
   ```

8. **du -sh --max-depth=1 / | grep total** - Estimates the size of files and directories, including their subdirectories, up to a maximum depth of 1.
   ```
   du -sh --max-depth=1 /
   ```
