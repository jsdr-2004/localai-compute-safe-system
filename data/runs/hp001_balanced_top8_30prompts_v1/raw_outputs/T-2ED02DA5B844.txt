`df -h` is an abbreviation for `df --help`, but more commonly used as `df -h`. This command-line utility in Unix-like operating systems (including Linux and macOS) is used to display disk usage information about file systems mounted on a system.

### What Does df -h Do?

The `-h` option stands for "human-readable" or "human-friendly." When you run the `df` command without any options, it displays file system sizes in bytes. Using the `-h` option makes these numbers more readable by converting them into kilobytes (K), megabytes (M), gigabytes (G), and so on.

For example:
- 1024 bytes = 1 KiB (kilobyte)
- 1024 KiB = 1 MiB (megabyte)

When you use `df -h`, the output looks like this:

```
Filesystem      Size  Used Avail Use% Mounted on
udev            7.8G     0   7.8G   0% /dev
tmpfs           1.6M     0   1.6M   0% /run
...
```

Here, the `Size`, `Used`, and `Avail` columns are now in human-readable format (e.g., MiB or GiB).

### Does df -h Change the System?

Running `df -h` does not change any system settings or files. It simply provides a summary of disk usage for all mounted file systems on your system. The command is purely informational and does not modify anything in the filesystem.

However, if you were to use other options with `df`, such as `-i` (to display inode information) or `-p` (to format output like a tree), those could potentially affect how data is displayed but would not change any system state. For example:

- Using `-i` might show the number of inodes available on each filesystem, which can be useful for understanding disk space usage from an inode perspective.
  
  ```bash
  df -i
  ```

- The `-p` option formats the output to resemble a tree structure, making it easier to understand directory structures.

  ```bash
  df -hP
  ```

In summary, `df -h` is used to get an overview of disk usage in a human-readable format and does not alter any system settings or files.
