To inspect a systemd service without modifying it, you can use the `systemctl` command with various options.

1. **List all services**: Use the `systemctl list-units` command to list all running and inactive services:
   ```bash
   systemctl list-units
   ```

2. **Inspect a specific service**: Use the `systemctl inspect` command followed by the name of the service you want to inspect:
   ```bash
   systemctl inspect myservice
   ```
   Replace "myservice" with the actual name of your service.

3. **Get detailed information about a service**: You can use the `-f` option along with `systemctl inspect` to get more detailed output:
   ```bash
   systemctl -f inspect myservice
   ```

4. **Check if a service is enabled or disabled**: Use the `systemctl status` command followed by the name of the service you want to check:
   ```bash
   systemctl status myservice
   ```
   Replace "myservice" with the actual name of your service.

5. **View logs for a service**: You can use the `journalctl` command along with the `-u` option to view logs for a specific service:
   ```bash
   journalctl -u myservice
   ```
   Replace "myservice" with the actual name of your service.

These commands provide detailed information about a systemd service without requiring any modifications.
