To inspect a systemd service without changing it, you can use the `journalctl` command. Here's an example of how to do it:

1. First, make sure that the service is running and enabled:
```bash
systemctl status <service_name>
```
Replace `<service_name>` with the actual name of your service.

2. Once the service is running, you can use `journalctl` to inspect its logs:
```bash
journalctl -u <service_name>
```
This will show you a list of recent journal entries for the specified service.

3. If you want to see more detailed information about the service, such as its configuration and environment variables, you can use the `-a` option:
```bash
journalctl -u <service_name> -a
```
This will display all available journal entries for the service.

4. To get a list of services that are currently running or stopped, you can use `journalctl` with the `-t` option:
```bash
journalctl -t
```
This will show you a list of all services that are currently running or stopped.

5. If you want to inspect the service's configuration files, such as its systemd unit file and environment variables, you can use `journalctl` with the `-p` option:
```bash
journalctl -p <service_name>
```
This will show you a list of all journal entries for the specified service.

Some common options used with `journalctl` include:

* `-u`: Show only units (services or containers) that are running.
* `-a`: Display additional information, such as configuration files and environment variables.
* `-t`: Show only services that are currently running or stopped.
* `-p`: Display only journal entries for a specific service.

By using `journalctl`, you can easily inspect the logs of a systemd service without changing it.
