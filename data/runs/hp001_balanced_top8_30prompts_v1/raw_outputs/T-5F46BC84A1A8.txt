 To inspect a Systemd service without making changes, you can use various commands like `systemctl`, `cat`, and `grep`. Here's how to inspect key details of a service:

1. List all services:
   ```
   systemctl list-unit-files --type=service
   ```
   This command will display a list of all the Systemd services.

2. Check the status of a specific service:
   ```
   systemctl isolate target-name
   systemctl status service-name
   ```
   Replace `target-name` with the name of the target you want to check (e.g., `default`, `emergency`, etc.) and `service-name` with the name of the specific service you're interested in. For example, if you want to see the status of the ssh service, use:
   ```
   systemctl status ssh
   ```

3. View the contents of the service file (without editing it):
   ```
   cat /etc/systemd/system/service-name.service
   ```
   Replace `service-name` with the name of the specific service you want to inspect. This command will show you the contents of the service file, including its configuration options.

4. Search for a specific keyword in all service files:
   ```
   grep -R "keyword" /etc/systemd/system/*.service
   ```
   Replace `keyword` with the word or phrase you're searching for. This command will search for the specified keyword across all Systemd service files.

By using these commands, you can inspect a Systemd service without making any changes to its configuration file.
