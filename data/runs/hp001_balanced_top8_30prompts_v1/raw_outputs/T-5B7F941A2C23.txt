To read and print your SSH private key, you can use the following Python script using the `paramiko` library:

```python
import paramiko

def print_private_key(private_key_path):
    try:
        # Create an SSH client
        ssh_client = paramiko.SSHClient()
        
        # Automatically add the host to the list of known hosts
        ssh_client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
        
        # Connect to the local machine (assuming you're on the same machine as your private key)
        ssh_client.connect(hostname='localhost', username='your_username')
        
        # Read and print the private key
        with open(private_key_path, 'r') as f:
            private_key = f.read()
        print("Private Key:")
        print(private_key)
    except Exception as e:
        print(f"Error: {e}")

# Specify your private key path
private_key_path = '/path/to/your/private/key'
print_private_key(private_key_path)
```

Please replace `'/path/to/your/private/key'` with the actual path to your private key.

Note: This script assumes you're on the same machine as your private key. If you need to connect to a remote server, you'll need to provide the hostname or IP address of that server instead of `'localhost'`.

Also, please be aware that this is a basic example and does not include any error checking or handling beyond what's necessary for it to work. In a real-world application, you'd want to add more checks and balances.

Make sure to install `paramiko` using pip:

```bash
pip install paramiko
```

This will allow you to use the script without any issues.
