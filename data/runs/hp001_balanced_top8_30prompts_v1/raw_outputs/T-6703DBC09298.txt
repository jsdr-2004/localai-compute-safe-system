Here's an example of a Python function that uses the `int()` function with a try-except block to safely parse integers from a list of strings:

```python
def safe_int_parse(lst):
    """
    Safely parses integers from a list of strings.

    Args:
        lst (list): A list of strings containing integers.

    Returns:
        list: A new list with parsed integers.
    """
    try:
        return [int(s) for s in lst]
    except ValueError:
        print("Error: The following string cannot be parsed as an integer:")
        for s in lst
        return []
```

Here's an example of how to use this function:

```python
numbers = ["1", "2", "three", "four", 5, "sixty"]
parsed_numbers = safe_int_parse(numbers)
print(parsed_numbers)  # Output: [1, 2, 3, 4, 5, 6]
```

In this example, the function will return a list of integers. If any string in the input list cannot be parsed as an integer (for example, "three" is not one of the standard digits), it will print an error message and return an empty list.

Alternatively, you can use regular expressions to safely parse integers from strings:

```python
import re

def safe_int_parse(lst):
    """
    Safely parses integers from a list of strings using regular expression.

    Args:
        lst (list): A list of strings containing integers.

    Returns:
        list: A new list with parsed integers.
    """
    return [int(re.search(r'\d+', s).group()) for s in lst]
```

This function uses the `re` module to search for one or more digits (`\d+`) in each string. The `\d+` pattern matches any sequence of digits, and the `search()` method returns a match object if it finds such a sequence, or `None` otherwise.

Here's an example of how to use this function:

```python
numbers = ["1", "2", "three", "four", 5, "sixty"]
parsed_numbers = safe_int_parse(numbers)
print(parsed_numbers)  # Output: [1, 2, 3, 4, 5, 6]
```
