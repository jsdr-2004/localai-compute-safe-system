```python
def safe_parse_integers(input_list):
    """
    Parses integers from a list of strings safely.
    
    Args:
        input_list (list): A list containing string elements that may represent integer values.
        
    Returns:
        list: A new list containing only the integer values parsed from the input list. Non-integer
               elements are skipped or ignored, depending on the implementation choice.
    """
    # Initialize an empty list to store valid integers
    result_list = []
    
    for item in input_list:
        try:
            # Attempt to convert the string to an integer
            int_value = int(item)
            result_list.append(int_value)
        except ValueError:
            # If conversion fails, skip this element and continue with the next one
            pass
    
    return result_list

# Example usage:
input_strings = ["123", "456", "789", "not_an_int"]
parsed_integers = safe_parse_integers(input_strings)
print(parsed_integers)  # Output: [123, 456, 789]
```

In this function:

- We initialize an empty list `result_list` to store the valid integer values.
- We iterate over each item in the input list. For each item:
  - We attempt to convert it to an integer using `int(item)`.
  - If successful, we append the converted value to `result_list`.
  - If a `ValueError` is raised (indicating that the conversion failed), we simply skip this element and continue with the next one.
