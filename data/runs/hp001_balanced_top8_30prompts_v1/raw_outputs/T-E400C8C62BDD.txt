 To inspect the memory usage in a read-only mode on a Linux system, you can use the following commands:

1. `free -r` : This command displays the total amount of free and used physical and swap memory in the system, but it's read-only because the `-r` flag makes it print only the raw data without headers or formatting.

2. `top -n 1 -b -o %Mem | grep -i mem` : This command runs top for a single iteration (`-n 1`) in batch mode (`-b`) and sorts the output by memory usage (`%Mem`). It then pipes the output to `grep` to filter only lines containing "mem", ensuring read-only access since it doesn't modify the underlying system.

3. `ps -eo psr,pid,pgid,ppid,sid,tty,stat,comm,%mem,%cpu,state --sort=-%mem` : This command displays a list of running processes sorted by memory usage (%mem). The `--sort=-%mem` flag reverses the sorting order, so that the process with the highest memory usage appears at the top.

For inspecting CPU load, you can use:

1. `uptime` : This command provides information about the current system uptime and the system's load averages for the past 1, 5, and 15 minutes. It is read-only since it only displays data without modifying the underlying system.

2. `top -n 1 -b` : This command shows a list of running processes sorted by CPU usage (default). Since it runs for a single iteration (`-n 1`) in batch mode (`-b`), it's also read-only.
