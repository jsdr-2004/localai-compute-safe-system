To find out which folders are using the most disk space without deleting anything, you can follow these steps:

**For Windows:**

1. Open File Explorer (Windows key + E).
2. Click on "View" in the top menu bar.
3. Check the box next to "Hidden items" and then click "OK".
4. In the left-hand sidebar, right-click on the folder you want to analyze (e.g., "C:\Users\YourUsername").
5. Select "Properties".
6. In the Properties window, click on the "Details" tab.
7. Look for the "Size" column and sort the files by size in descending order.

Alternatively, you can use the built-in Disk Cleanup tool:

1. Open File Explorer (Windows key + E).
2. Click on "This PC" or "Computer".
3. Right-click on the drive you want to analyze (e.g., C:).
4. Select "Properties".
5. In the Properties window, click on the "Disk Cleanup" button.
6. Follow the prompts to scan and clean up unnecessary files.

**For macOS:**

1. Open Finder (press Command + Space or click on the Finder icon in the dock).
2. Click on "Go" in the top menu bar.
3. Select "About This Mac".
4. Click on "Storage".
5. In the Storage window, click on the "Manage" button next to the drive you want to analyze (e.g., Macintosh HD).
6. In the Manage window, click on the "Files and folders" tab.
7. Sort the files by size in descending order.

Alternatively, you can use the built-in Disk Utility:

1. Open Disk Utility (Applications > Utilities).
2. Select the drive you want to analyze from the left-hand sidebar.
3. Click on the "Analyze" button.
4. In the Analysis window, click on the "Size" column and sort the files by size in descending order.

**For Linux:**

1. Open a terminal window (e.g., Konsole or Terminal).
2. Type `df -h` to display disk usage information.
3. Look for the folder with the largest size.

Note that these methods will show you which folders are using the most disk space, but they won't tell you why those files are taking up so much space.
