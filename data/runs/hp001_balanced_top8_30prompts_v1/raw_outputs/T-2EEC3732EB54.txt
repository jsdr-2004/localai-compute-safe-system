Debugging Checklist for Memory-Intensive Processes in Python
===========================================================

When a Python process is using excessive memory, it can be challenging to identify the root cause. Follow this step-by-step debugging checklist to help you pinpoint and resolve the issue.

### Step 1: Collect System Information

1. **Check system resources**: Use `top` or `htop` to check the current system resources (CPU, RAM, disk usage) to ensure that your process is not consuming excessive resources.
2. **Monitor memory usage**: Run `ps -ef | grep python` or `tasklist` (on Windows) to verify the process's memory usage.

### Step 2: Inspect Memory Usage

1. **Use the `psutil` library**: Install `psutil` using pip (`pip install psutil`) and use it to monitor memory usage:
   ```python
import psutil
print(psutil.Process().memory_percent())
```
2. **Analyze process memory**: Use `pmap -d <process_id>` (on Linux) or `tasklist /pid:<process_id>` (on Windows) to visualize the process's memory layout.

### Step 3: Identify Memory Leaks

1. **Use a garbage collector**: Implement a `gc.collect()` call after your Python script finishes executing:
   ```python
import gc
# ... rest of your code ...
gc.collect()
```
2. **Check for cyclic references**: Use the `weakref` module to detect potential memory leaks:
   ```python
import weakref
for obj in [obj1, obj2, ...]:
    if not isinstance(obj, (type(None), int)):
        ref = weakref.ref(obj)
        if ref() is not None:
            # Handle cyclic reference
```
3. **Inspect objects for large memory allocations**: Use `sys.getsizeof()` to estimate the size of individual objects.

### Step 4: Investigate Object Creation

1. **Analyze object creation patterns**: Review your code's object creation logic to ensure that unnecessary or large objects are not being created.
2. **Use a profiler**: Utilize a profiling tool like `cProfile` or `line_profiler` to identify performance bottlenecks and memory-intensive operations.
