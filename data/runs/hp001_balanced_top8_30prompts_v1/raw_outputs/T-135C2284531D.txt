 To verify if Docker is installed on your system, you can use the following methods:

1. **Docker Version**: Open a terminal or command prompt and run the command `docker --version`. If Docker is installed correctly, it will display the Docker version along with other details. For example:

```bash
$ docker --version
Docker version 20.10.7, build 370c28f
```

2. **Check Docker Images**: Another way to check if Docker is installed is by listing the available images with `docker images`. If you have Docker installed and running, it will show a list of images or display a message saying "no images found".

```bash
$ docker images
REPOSITORY          TAG       IMAGE ID       CREATED         SIZE
```

3. **Check Docker Containers**: You can also verify Docker installation by listing the active containers with `docker ps`. If there are no running containers, you'll see a message saying "No Running Containers".

```bash
$ docker ps
CONTAINER ID   IMAGE     COMMAND   CREATED   STATUS    PORTS     NAMES
```

If none of these commands are recognized, Docker might not be installed on your system or it's not added to the system PATH. In that case, you should reinstall Docker or configure the PATH accordingly.
