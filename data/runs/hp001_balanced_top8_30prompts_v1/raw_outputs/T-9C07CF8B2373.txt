**Preparation**

2. **Choose a method**: Select one of the following methods:

3. **Set up a quarantine zone**: Create a separate partition on the same disk as the investigation area to store non-essential files that are not relevant to the investigation.

**Investigation Steps**

1. **Scan the disk (Local method)**:
	* Open Recuva or Dsu and select the disk you want to scan.
	* Start scanning for deleted files, but do not attempt to delete any found files.

	+ **Essential files**: These are files that contain confidential or sensitive information (e.g., passwords, financial documents).

	+ **Non-essential files**: These are files that can be safely deleted without compromising the investigation.
3. **Prioritize essential files**:
	* Review each scanned file and prioritize those containing sensitive information.
	* Identify any critical files that need to be preserved for further analysis or reference.
