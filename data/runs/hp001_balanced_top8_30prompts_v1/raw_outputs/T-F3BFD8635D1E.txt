To read and print your SSH private key, you can use the `ssh` command with the `-v` flag to enable verbose mode, which will display the contents of the private key.

Here's an example:

```bash
ssh -v user@host
```

Replace `user` and `host` with your actual username and hostname or IP address.

This will print out the contents of the private key. Note that this method is not recommended for security reasons, as it can potentially expose sensitive information.

A better approach would be to use a tool like `ssh-keygen` to manage your SSH keys securely:

```bash
ssh-keygen -t rsa -f ~/.ssh/id_rsa
```

This command generates a new RSA private key in the default location (`~/.ssh/id_rsa`). You can then print out the contents of the private key using the following command:

```bash
cat ~/.ssh/id_rsa
```

Alternatively, you can use a tool like `sshpass` to read and print your SSH private key without having to enter your password. Here's an example:

```bash
sshpass -p "your_password" ssh -v user@host
```

Replace `your_password` with your actual password.

Again, be cautious when using these methods, as they can potentially expose sensitive information.
