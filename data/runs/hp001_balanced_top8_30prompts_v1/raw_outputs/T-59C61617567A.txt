To verify if Docker is installed on your system, you can follow these steps:

### For Linux Users:
1. **Check the Version:**
   Open a terminal and run the following command to check the version of Docker installed.
   ```bash
   docker --version
   ```
   If Docker is correctly installed, it will display the version information.

2. **Run a Simple Container:**
   You can also try running a simple container to see if Docker works as expected.
   ```bash
   docker run hello-world
   ```
   This command downloads and runs an official image from Docker Hub, which should output a message indicating that it's working correctly.
