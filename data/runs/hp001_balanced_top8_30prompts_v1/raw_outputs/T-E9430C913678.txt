You can use the following commands to inspect a systemd service without modifying it:

1. Check the service file:
   ```bash
sudo systemctl status <service_name>
```

   This command will show you the current status of the service, including any error messages.

2. List all services:
   ```bash
systemctl list-units --type=service
```

   This command will display a list of all systemd services, including their current status and status since boot.

3. Check the service's configuration file:
   ```bash
sudo systemctl edit <service_name>
```

   This command will open the default editor for the service's configuration file in read-only mode. You can inspect the contents of the file without making any changes.

4. Use `systemctl show` to get detailed information about a service, including its status, description, and dependencies.
   ```bash
sudo systemctl show <service_name>
```

5. Check if a service is enabled or disabled:
   ```bash
sudo systemctl is-enabled <service_name>
```

   This command will return "enabled" if the service is enabled and "disabled" otherwise.

6. Check the last boot time of a service:
   ```bash
systemctl status <service_name> | grep Last Boot
```

   This command will display the last boot time of the service in seconds since the epoch (January 1, 1970).
