 To inspect a systemd service without changing it, you can use various commands that provide information about the service configuration, status, and behavior. Here are some examples using the `systemctl` command:

1. List all services (unit files):
   ```
   systemctl list-units --type=service
   ```

2. Get detailed information for a specific service:
   ```
   systemctl show <service_name>
   ```
   Replace `<service_name>` with the name of the service you want to inspect (e.g., `systemd-resolved`).

3. Check the status and active state of a service:
   ```
   systemctl status <service_name>
   ```
   If you want to see only the status and not the service logs, use:
   ```
   systemctl is-active <service_name>
   ```

4. Check if the service is enabled on startup:
   ```
   systemctl is-enabled <service_name>
   ```
   If the output shows `enabled`, it means the service will start at boot time.

5. List all active services (running or exited):
   ```
   systemctl list-units --state=active --type=service
   ```

6. Check the journal logs for a specific service:
   ```
   journalctl -u <service_name>
   ```
   You can also filter the log output based on priority, such as `-p err` to see only error messages.
