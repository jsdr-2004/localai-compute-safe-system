Here's a step-by-step guide to installing and verifying Docker on Ubuntu:

**Step 1: Install Prerequisites**

Before installing Docker, make sure you have the necessary prerequisites installed:
```bash
sudo apt update && sudo apt install -y ca-certificates curl gnupg lsb-release
```
This will update the package list and install any required dependencies.

**Step 2: Add Docker GPG Key and Repository**

Add the official Docker repository to your system:
```bash
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo apt-key add -
sudo add-apt-repository "deb [arch=amd64] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable"
```
This will add the GPG key for Docker and configure the repository.

**Step 3: Install Docker Engine**

Install the Docker engine:
```bash
sudo apt update && sudo apt install -y docker-ce
```
This will download and install the Docker engine.

**Step 4: Start Docker Service and Verify Installation**

Start the Docker service and verify that it's running:
```bash
sudo systemctl start docker
sudo systemctl enable docker
docker --version
```
The last command should display the version of Docker installed on your system.

**Step 5: Verify Docker Installation (Optional)**

Verify that Docker is working correctly by running a simple container:
```bash
sudo docker run -it ubuntu /bin/bash
```
This will start a new container based on the Ubuntu image and open a bash shell inside it. You can then verify that you're in a new shell session with `echo $RANDOM`.

That's it! You should now have Docker installed and verified on your Ubuntu system.

Note: Make sure to replace `ubuntu` with the desired image name if you want to use a different base image.
```bash
sudo docker run -it <image_name> /bin/bash
```
Example: `sudo docker run -it python:3.9-slim /bin/bash`

Verify Docker installation:
```bash
docker --version
```
This command will display the version of Docker installed on your system.

Optional: To enable Docker to start automatically when you log in, add the following line to `/etc/systemd/system/docker.service`:
```bash
[Service]
ExecStart=/usr/bin/dockerd -D --config /etc/docker/daemon.json
```
