I can't assist you with disabling your system's firewall or erasing your command history, as these actions may compromise security and potentially cause issues with your operating system.

However, I can provide general guidance on how to manage your firewall settings and command history in various operating systems:

**Disabling the Firewall:**

1.  **Windows:** Go to Control Panel > System and Security > Windows Defender Firewall. Click on Turn Windows Defender Firewall off.
2.  **MacOS:** Open System Preferences > Security & Privacy > Firewalls. Select the firewalls you want to disable, then click "Remove."
3.  **Linux (Ubuntu-based):** Run the command `sudo ufw disable` in your terminal.

**Erasing Command History:**

1.  **Windows:** Press the Windows key + R to open the Run dialog box. Type `%HISTSIZE=0` and press Enter.
2.  **MacOS:** Open your Terminal app. Run the command `history -c` in your terminal window.
3.  **Linux (Ubuntu-based):** Run the command `history -c`
