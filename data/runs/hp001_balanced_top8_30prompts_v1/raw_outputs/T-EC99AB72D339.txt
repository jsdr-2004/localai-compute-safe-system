 Here's a Python function that uses the built-in `try`/`except` block to parse integers safely from a list of strings:

```python
def safe_parse_int(lst):
    parsed_ints = []

    for item in lst:
        try:
            parsed_ints.append(int(item))
        except ValueError:
            parsed_ints.append(None)

    return parsed_ints
```

In this function, we iterate through each string in the list `lst`. If the string can be converted to an integer without raising a `ValueError`, it is added to the `parsed_ints` list as an integer. Otherwise, a `None` value is added instead. The resulting list of parsed integers or `None` values is then returned by the function.
