**Safe Integer Parsing Function**
=====================================

The following Python function uses the `str.isdigit()` method to safely parse integers from a list of strings.

```python
def safe_parse_integers(string_list):
    """
    Safely parses integers from a list of strings.

    Args:
        string_list (list): A list of strings containing potential integer values.

    Returns:
        list: A list of parsed integers.
    """
    return [int(s) for s in string_list if s.isdigit()]
```

**Example Use Cases**
---------------------

```python
# Test the function with a list of strings
strings = ["123", "abc", "456", "789"]
parsed_integers = safe_parse_integers(strings)
print(parsed_integers)  # Output: [123, 456]

# Test the function with an empty list
empty_list = []
parsed_integers = safe_parse_integers(empty_list)
print(parsed_integers)  # Output: []

# Test the function with a list containing non-integer strings
non_integer_strings = ["abc", "def"]
parsed_integers = safe_parse_integers(non_integer_strings)
print(parsed_integers)  # Output: []
```

**Explanation**
---------------

This function uses a list comprehension to iterate over each string in the input list. It checks if each string contains only digits using `s.isdigit()`. If it does, the integer is parsed and added to the output list.

The `str.isdigit()` method returns `True` if all characters in the string are digits, otherwise it returns `False`. This approach ensures that non-integer strings are ignored.
