Certainly! Here are some read-only (non-modifying) Linux commands that you can use to inspect the system's memory and CPU load:

### Memory Inspection

1. **`free`**
   - This command provides a summary of physical and swap memory usage.
   ```sh
   free
   ```

2. **`vmstat`**
   - `vmstat` is used for monitoring virtual memory statistics, including the amount of physical memory in use.
   ```sh
   vmstat 1 5 # This will display stats every second for 5 seconds
   ```
   - You can also specify different options to get more detailed information:
     ```sh
     vmstat -s
     ```

3. **`cat /proc/meminfo`**
   - Provides detailed memory usage statistics.
   ```sh
   cat /proc/meminfo
   ```

### CPU Load Inspection

1. **`uptime`**
   - Shows the system's uptime and average load over the last 1, 5, and 15 minutes.
   ```sh
   uptime
   ```

2. **`top` or `htop`**
   - These commands provide a real-time view of running processes and their CPU usage.
   ```sh
   top # For older systems that don't have htop installed
   ```
   - If you have `htop`, it provides more interactive control over the display:
   ```sh
   htop
   ```

3. **`sar`**
   - The `sar` command collects and reports system activity statistics.
   ```sh
   sar -u 1 5 # Reports CPU usage every minute for 5 minutes
   ```
   - You can also use it to get other types of data, such as disk I/O:
   ```sh
   sar -d 1 5
   ```

4. **`mpstat`**
   - Part of the `sysstat` package, this command provides detailed statistics on CPU usage.
   ```sh
   mpstat 1 5 # Reports every second for 5 seconds
   ```
   - You can also specify different options to get more detailed information:
   ```sh
   mpstat -P ALL 1 5
   ```

These commands should help you gather the necessary information about your system's memory and CPU load without making any changes.
