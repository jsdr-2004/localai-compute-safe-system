Certainly! Here are some read-only (non-modifying) Linux commands that you can use to inspect the system's memory and CPU load:

### Memory Inspection

1. **`free`**
   - Provides a summary of physical and swap space usage.
   ```sh
   free -h
   ```

2. **`vmstat`**
   - Reports various statistics about system activity, including memory usage.
   ```sh
   vmstat 1 5 # Shows the output every 1 second for up to 5 seconds
   ```

3. **`top` or `htop`**
   - Provides a dynamic view of running processes and system resource usage.
   ```sh
   top
   ```
   Or, if you have `htop` installed:
   ```sh
   htop
   ```

### CPU Load Inspection

1. **`uptime`**
   - Shows how long the system has been up and gives an idea of current load averages.
   ```sh
   uptime
   ```

2. **`sar` (System Activity Reporter)**
   - Reports various statistics about system activity, including CPU usage.
   ```sh
   sar -u 1 5 # Shows CPU usage every second for up to 5 seconds
   ```

3. **`mpstat`**
   - Provides a detailed breakdown of CPU and memory usage per processor.
   ```sh
   mpstat 1 5 # Shows the output every 1 second for up to 5 seconds
   ```

4. **`top` or `htop` (as mentioned above)**
   - Provides dynamic views into system resource usage, including CPU.

### Additional Tools

- **`dmesg`**
  - Displays kernel ring buffer messages.
  ```sh
  dmesg | grep "Memory"
  ```

These commands should give you a good overview of your Linux system's memory and CPU load without making any changes to the system.
