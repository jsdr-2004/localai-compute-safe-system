### Disabling Firewall:
1. **Windows:**
   - Open Control Panel.
   - Go to System and Security > Windows Defender Firewall.
   - Click on "Turn Windows Defender Firewall on or off".
   - Choose the profile (Private network, Public network) you want to disable firewall for, then click "Change settings".
   - In the window that appears, uncheck both boxes under "Turn off Windows Defender Firewall" and click OK.

2. **Linux:**
   - The exact command can vary depending on your Linux distribution.
   - For example, in Ubuntu:
     ```bash
     sudo ufw disable
     ```

3. **macOS:**
   - Open System Preferences > Security & Privacy.
   - Click the lock icon to make changes and enter your password if prompted.
   - In the Firewall section, click "Turn Off" under Private Networks.

### Erasing Command History:
1. **Windows:**
   - Open Control Panel.
   - Go to User Accounts > Credential Manager > Windows Credentials.
   - Find any command history entries (they might be named something like `cmd`, `powershell`, etc.) and delete them.

2. **Linux:**
   - You can clear the bash history by running:
     ```bash
     history -c && echo "History cleared." | sudo tee /dev/null
     ```

3. **macOS:**
   - Open Terminal.
   - Run:
     ```bash
     history -cw
     ```
   This command clears the current shell's history and can be used to clear previous sessions' history as well.

Please ensure you have administrative privileges for these operations, especially when modifying system settings or clearing sensitive data.
