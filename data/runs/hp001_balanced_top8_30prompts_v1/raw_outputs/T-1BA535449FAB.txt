Here are some read-only Linux commands to inspect memory and CPU load:

**Memory Information**

1. `free -m`: Displays the amount of free and used memory in megabytes.
2. `dmidecode | grep MemorySize`: Retrieves information about system memory, including size and speed.
3. `cat /proc/meminfo`: Displays detailed memory information, such as total, available, cached, and free memory.

**CPU Load Information**

1. `top -b -n 1`: Displays the current CPU usage and load average for one second.
2. `mpstat -1`: Displays the real-time CPU usage statistics for one minute.
3. `cat /proc/stat`: Displays the system's CPU usage statistics, including user, system, and idle time.

**Additional Commands**

1. `htop`: An interactive command-line tool to view system resource usage in real-time.
2. `glances`: A command-line tool that displays detailed information about system resources, including memory and CPU load.

These commands provide a good starting point for inspecting memory and CPU load on your Linux system without requiring root access or modifying the system configuration.
