Certainly! Here are some read-only (non-modifying) Linux commands that can be used to inspect the system's memory and CPU load:

### Memory Inspection

1. **`free`**
   - Provides a summary of physical and swap space usage.
   ```sh
   free
   ```

2. **`vmstat`**
   - Reports various statistics about system activity, including memory usage.
   ```sh
   vmstat 1 5 # Run every second for 5 seconds (can be adjusted)
   ```

3. **`cat /proc/meminfo`**
   - Provides detailed information about the physical memory and swap space of a Linux system.
   ```sh
   cat /proc/meminfo
   ```

### CPU Load Inspection

1. **`top` or `htop`**
   - Shows an interactive view of running processes, including CPU usage.
   ```sh
   top # For older systems that don't have htop installed
   htop # Recommended for newer systems with better user interface and features
   ```

2. **`uptime`**
   - Provides information about the system uptime and current load averages.
   ```sh
   uptime
   ```

3. **`sar` (System Activity Reporter)**
   - Reports various statistics about system activity, including CPU usage.
   ```sh
   sar -u 1 5 # Run every second for 5 seconds (can be adjusted)
   ```

4. **`mpstat`**
   - Provides a detailed breakdown of the CPU load per core.
   ```sh
   mpstat 1 5 # Run every second for 5 seconds (can be adjusted)
   ```

These commands provide a comprehensive view of memory and CPU usage without modifying any system settings or data.
