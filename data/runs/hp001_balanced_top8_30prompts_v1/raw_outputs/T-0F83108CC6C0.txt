Here are some read-only Linux commands to inspect disk usage:

1. `df -h`:
   Displays a list of all file systems on the system, along with their current disk usage and available space.

2. `du -sh /`:
   Displays the total size of all files and directories in the root directory, grouped by department.

3. `lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT,USE`:
   Lists block devices on the system, along with their file type, size, mount point, and current usage (as a percentage).

4. `fdisk -l`:
   Displays information about all disk partitions on the system.

5. `pmap -d | grep total`:
   Displays the total amount of memory used by each process running on the system.

6. `free -h`:
   Displays the current state of the system's RAM and swap space, along with the percentage of usage for each.

7. `df -i`:
   Displays information about file systems, including their inode count (number of inodes used).

8. `du -sh /* | grep total`:
   Similar to `du -sh /`, but this command searches all directories on the system instead of just the root directory.

9. `ls -lh /dev/*`:
  Displays information about all block devices on the system, including their size and current usage.

10. `du -h | grep total`:
   Displays a list of all file systems on the system, along with their current disk usage and available space.
