```python
def safe_parse_ints(string_list):
    """
    Safely parses integers from a list of strings. Returns a list of integers.
    
    Parameters:
        string_list (list): A list of strings to be parsed into integers.
        
    Returns:
        list: A list containing only the valid integer values from the input list.
    """
    # Initialize an empty list to store the results
    result = []
    
    for item in string_list:
        try:
            # Attempt to convert the string to an integer
            num = int(item)
            # Append the converted number to the result list if it's a valid integer
            result.append(num)
        except ValueError:
            # Ignore non-integer strings and continue with the next one
            pass
    
    return result

# Example usage:
example_list = ["123", "456", "abc", "789"]
parsed_integers = safe_parse_ints(example_list)
print(parsed_integers)  # Output: [123, 456, 789]
```

In this function:

- We initialize an empty list `result` to store the valid integer values.
- We iterate through each item in the input list `string_list`.
- For each item, we attempt to convert it to an integer using `int(item)`. If successful (i.e., if the string can be converted into a number), we append the result to our `result` list.
- If conversion fails (raises a `ValueError`), we simply ignore the current item and continue with the next one.

This function ensures that only valid integers are included in the final output, while any non-integer strings are ignored.
