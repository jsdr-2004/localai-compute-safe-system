 Here's a Python function that uses the built-in `try/except` block to parse integers safely from a list of strings:

```python
def safe_parse_int_list(input_list):
    parsed_list = []
    for item in input_list:
        try:
            number = int(item)
            parsed_list.append(number)
        except ValueError:
            print(f"{item} is not a valid integer.")
    return parsed_list
```

This function takes a list of strings as input, iterates through each string, and attempts to convert it into an integer using the `int()` function. If the conversion is successful, the number is added to the `parsed_list`. If there's a ValueError, which occurs when the string cannot be converted to an integer, a message is printed indicating that the item is not a valid integer, and the loop continues with the next string in the list.

After processing all strings in the input list, the function returns the parsed_list containing only integers. If there were any invalid integers in the original list, they won't be included in the output list.
