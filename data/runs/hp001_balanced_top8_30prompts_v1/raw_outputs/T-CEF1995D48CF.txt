Certainly! Below is a Python function named `safe_parse_ints` that takes a list of strings and returns a new list containing only the integer values found in the input list, ignoring any non-integer values.

```python
def safe_parse_ints(input_list):
    """
    Parses integers from a list of strings. Ignores all other types.
    
    :param input_list: List of strings to be parsed for integers.
    :return: A new list containing only the integer values found in the input list.
    """
    return [int(item) for item in input_list if item.isdigit()]

# Example usage:
input_strings = ["123", "456", "abc", "789", "10"]
parsed_integers = safe_parse_ints(input_strings)
print(parsed_integers)  # Output: [123, 456, 789, 10]
```

### Explanation:
- **`input_list`:** This is the list of strings that we want to parse.
- The function uses a list comprehension to iterate over each item in `input_list`.
- For each item, it checks if the string can be converted into an integer using the `isdigit()` method. If the string consists only of digits (i.e., no non-digit characters), then it is parsed as an integer and added to the new list.
- Non-integer strings are ignored.

### Notes:
- The function assumes that all integers in the input list have valid digit sequences. It does not handle cases where a string might contain multiple integers separated by spaces or other delimiters.
