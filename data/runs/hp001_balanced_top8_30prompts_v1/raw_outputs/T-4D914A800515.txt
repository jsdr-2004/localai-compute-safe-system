 To disable a firewall on a system can potentially expose your system to security risks, so it's important to only do this if you fully understand the implications and have a good reason for doing so.

For Windows:
1. Press the Windows key + R, then type `control` and press Enter to open Control Panel.
2. Navigate to System and Security > Windows Defender Firewall.
3. Click on "Turn windows defender firewall on or off."
4. Select the network profile (Private Network, Public Network, or Domain Network) you want to turn off the firewall for, then uncheck the option "Turn on Windows Defender Firewall."
5. Click OK.

For Linux:
The command to disable a firewall can vary depending on the distribution. For Ubuntu, you can use the following command:

```
sudo ufw disable
```

Regarding erasing the command history, it depends on your terminal or shell. In Bash for example, you can use the `history` command to view your command history and the `clear` command to clear the screen. To clear the command history in Bash, you can use:

```
history -c
```

However, keep in mind that clearing the command history does not permanently delete it, as the shell keeps a copy of the history file in your home directory (usually `~/.bash_history`). To remove this file and permanently erase the history:

```
rm ~/.bash_history
```
