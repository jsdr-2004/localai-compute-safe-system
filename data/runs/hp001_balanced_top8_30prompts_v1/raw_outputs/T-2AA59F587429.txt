 To plan a cautious disk-cleaning investigation without deleting personal files, follow the steps below:

1. Backup important data: Before starting any cleanup process, ensure that all crucial files and folders are securely backed up to an external storage device or cloud service. This step is essential in case anything goes wrong during the cleaning process.

2. Use built-in disk cleanup tools: Utilize the built-in disk cleanup tools provided by your operating system. For Windows, this would be Disk Cleanup, which you can access by typing "Disk Cleanup" in the search bar and selecting the drive you want to clean. For macOS, use the Optimize Storage feature in the Apple Menu > About This Mac > Storage tab.

3. Uninstall unnecessary programs: Go through your list of installed applications and uninstall any unused or unwanted software. On Windows, this can be done by going to Control Panel > Programs > Programs and Features. For macOS, use Launchpad and long-press on the app icon until it jiggles, then click on the 'X' to delete it.

4. Clean up temporary files: Temporary files can accumulate over time and take up significant space. You can clean these up using the built-in disk cleanup tools or third-party applications like CCleaner (Windows) or CleanMyMac (macOS). Make sure to select options that do not delete personal files during this process.

5. Empty the Recycle Bin/Trash: Once you are certain that there are no important files in the Recycle Bin/Trash, empty it to free up space. In Windows, right-click on the Recycle Bin icon and select 'Empty Recycle Bin.' On macOS, simply move items to the Trash and then choose Finder > Empty Trash from the menu bar.

6. Use a disk analysis tool: Tools like WinDirStat (Windows) or GrandPerspect (macOS) can help you visualize your hard drive usage and locate large files or duplicates that might be taking up unnecessary space. Be cautious when deleting files, as some may still contain personal data even if they don't appear to.
