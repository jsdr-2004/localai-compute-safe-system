Certainly! Here are some essential read-only (non-modifying) Linux commands that you can use to inspect disk usage:

1. **`df -h`**
   - This command provides an overview of the amount of space used and available on your file systems, with output formatted in a human-readable format.

2. **`du -sh /path/to/directory`**
   - The `-s` option tells `du` to summarize the sizes for each directory by showing only one number per directory.
   - The `/path/to/directory` should be replaced with the path of the directory you want to inspect.
   - This command gives a summary size (in human-readable format) of the specified directory.

3. **`ncdu /path/to/directory`**
   - `ncdu` is an interactive file system usage analysis tool that provides detailed information about files and directories in a user-friendly manner. It allows you to navigate through directories, see their sizes, and perform operations like searching for specific files.
   - Replace `/path/to/directory` with the directory you want to inspect.

4. **`lsblk`**
   - This command lists all of the block devices (like hard drives or partitions) available on your system along with their mount points and other details.
   - It's useful for understanding which directories are mounted where.

5. **`mount`**
   - The `mount` command shows you what file systems are currently mounted at various locations in your filesystem hierarchy, including the root directory (`/`) and any additional partitions or drives that have been added to your system.

6. **`find /path/to/directory -type f -exec du -h {} +`**
   - This command finds all files (not directories) within a specified directory and its subdirectories, then uses `du -h` to show their sizes.
   - Replace `/path/to/directory` with the path of the directory you want to inspect.

7. **`ncursesdu /path/to/directory`**
   - Similar to `ncdu`, this tool provides an interactive file system usage analysis interface, but it uses ncurses for its user interface instead of a graphical one.

8. **`lsof +D /path/to/directory`**
   - The `-a` option can be used with `lsof` to list all open files in the specified directory.
   - This command is useful if you want to see which processes are using files within a specific directory.
