 To write PyTest tests for a function that reverses a string, you'll need to have the reverse string function first. Here's a simple example of such a function:

```python
def reverse_string(input_str):
    return input_str[::-1]
```

Now let's create a test case for this function using PyTest. Create a new file named `test_reverse_string.py` and include the following content:

```python
import pytest

def test_reverse_string():
    assert reverse_string("hello") == "olleh"
    assert reverse_string("world") == "dlrow"
    assert reverse_string("Python") == "notyP"
    assert reverse_string("test") == "setT"
    assert reverse_string("") == ""

def test_reverse_empty_string():
    assert reverse_string("") is None

def test_reverse_non_string():
    with pytest.raises(TypeError):
        reverse_string(123)
```

In this example, I created three tests:

1. `test_reverse_string()` tests the function's behavior for different input strings.
2. `test_reverse_empty_string()` checks if an empty string returns an empty string or None (you can choose to return None when encountering an empty string).
3. `test_reverse_non_string()` verifies that the function raises a TypeError when given a non-string input.

To run the tests, execute `pytest test_reverse_string.py` in your terminal, and PyTest will report whether each test passed or failed.
