When using `docker ps`, if you encounter a "permission denied" error, it typically indicates that the Docker daemon is not running or there's an issue with your user permissions to interact with the Docker service. Here are some common reasons and troubleshooting steps:

### 1. Docker Daemon Not Running
- **Check Docker Status**: Ensure that the Docker daemon is running.
  ```sh
  sudo systemctl status docker
  ```
  If it’s not running, start it:
  ```sh
  sudo systemctl start docker
  ```

### 2. User Permissions
- **Run as Root or Use `sudo`**: Sometimes, you need to run the command with elevated privileges.
  ```sh
  sudo docker ps
  ```
- **Check Docker Group Membership**: Ensure that your user is a member of the Docker group.
  ```sh
  id -nG $(whoami)
  ```
  If not, add yourself:
  ```sh
  sudo usermod -aG docker $(whoami)
  ```

### 3. SELinux or AppArmor (Linux-specific issues)
- **SELinux**: If you are using SELinux and Docker is running in permissive mode, it might be causing permission issues.
  ```sh
  sudo setenforce 0
  ```
- **AppArmor**: Similarly, if you have AppArmor enabled, ensure that the necessary profiles are correctly configured.

### 4. Docker Service Configuration
- **Check Docker Configuration Files**: Sometimes, configuration files can cause issues. Check `/etc/docker/daemon.json` and make sure it is correctly set up.
- **Restart Docker Service**: After making changes to configuration files, restart the Docker service:
  ```sh
  sudo systemctl restart docker
  ```

### 5. Network Issues
- **Docker Daemon Configuration**: Ensure that your Docker daemon’s network settings are correct and allow connections from your machine.

### 6. Docker Image Permissions
- **Ensure Correct Image Ownership**: Sometimes, images might be owned by a different user or group. You can change the ownership of an image:
  ```sh
  sudo chown $(id -u):$(id -g) /path/to/image.tar
  ```

### 7. Docker Version Compatibility
- **Check for Known Issues**: Ensure that your version of Docker is compatible with your system and other software you are using.
