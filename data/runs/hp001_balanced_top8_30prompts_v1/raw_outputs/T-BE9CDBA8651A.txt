Certainly! Here are some read-only (non-modifying) Linux commands that you can use to inspect the system's memory and CPU load:

### Memory Inspection

1. **`free`**
   - Provides a summary of physical and swap memory usage.
   ```sh
   free -h
   ```

2. **`vmstat`**
   - Reports various statistics about system activity, including memory usage.
   ```sh
   vmstat 1 5 # Run every second for 5 seconds
   ```
   
3. **`top` or `htop`**
   - Provides a dynamic view of running processes and their resource usage.
   ```sh
   top # For the traditional `top`
   htop # For an alternative, more user-friendly interface (requires installation)
   ```

### CPU Load Inspection

1. **`uptime`**
   - Shows how long the system has been up and gives load averages for the past 1, 5, and 15 minutes.
   ```sh
   uptime
   ```

2. **`sar`**
   - Collects and reports various statistics about system activity, including CPU usage.
   ```sh
   sar -u 1 5 # Run every second for 5 seconds
   ```
   
3. **`mpstat` (part of `sysstat` package)**
   - Reports per-CPU statistics on a per-second basis.
   ```sh
   mpstat 1 5 # Run every second for 5 seconds
   ```

### Example Usage

Here's an example of how you might use some of these commands together:

```sh
# Show memory usage in human-readable format
free -h

# Show CPU load statistics over the last 5 minutes
uptime

# Show per-CPU statistics every second for 5 seconds
mpstat 1 5
```

These commands will give you a comprehensive view of your system's memory and CPU usage without making any changes to the system.
