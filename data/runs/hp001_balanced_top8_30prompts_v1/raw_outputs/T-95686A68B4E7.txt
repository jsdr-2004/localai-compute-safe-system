```python
def safe_parse_ints(string_list):
    """
    Parses integers from a list of strings. Returns a list of integers.
    
    Args:
        string_list (list): A list of strings that are expected to represent integers.
        
    Returns:
        list: A list of integers parsed from the input list.
        
    Raises:
        ValueError: If any element in the input list cannot be converted to an integer.
    """
    int_list = []
    
    for item in string_list:
        try:
            # Attempt to convert each string to an integer
            num = int(item)
            int_list.append(num)
        except ValueError as e:
            # Raise a more descriptive error message if conversion fails
            raise ValueError(f"Could not parse '{item}' into an integer: {e}")
    
    return int_list

# Example usage:
try:
    result = safe_parse_ints(["123", "456", "789"])
    print(result)  # Output: [123, 456, 789]
except ValueError as e:
    print(e)

try:
    result = safe_parse_ints(["123", "abc", "789"])
    print(result)
except ValueError as e:
    print(e)  # Expected output: Could not parse 'abc' into an integer
```

In this function, we use a `try-except` block to catch any `ValueError` that occurs when attempting to convert a string to an integer. If the conversion fails, it raises a custom `ValueError` with a more descriptive message.
