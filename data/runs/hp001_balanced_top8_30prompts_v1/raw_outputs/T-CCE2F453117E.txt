To verify if Docker is installed on your system, you can follow these steps:

### For Linux Users:
1. **Check the Version:**
   Open a terminal and run the following command to check the version of Docker:
   ```bash
   docker --version
   ```
   If Docker is installed, it will display its version number.

2. **Run a Simple Container:**
   You can also try running a simple container using the `docker` command:
   ```bash
   docker run hello-world
   ```
   This command downloads and runs an image from Docker Hub, which should output "Hello from Docker!" if Docker is correctly installed and configured.
