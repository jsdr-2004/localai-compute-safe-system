Here are some read-only Linux commands to inspect disk usage:

1. **df** (Disk Free) - Displays the amount of free space on each file system.
   ```
   df -h
   ```

2. **du** (Disk Usage) - Displays the size of files and directories, including their total size and how much is used.
   ```
   du -sh /
   ```

3. **lsblk** (List Block Devices) - Displays information about block devices such as hard drives, partitions, and file systems.
   ```
   lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
   ```

4. **fdisk** (File Disk) - Displays the partition table of a disk.
   ```
   fdisk -l
   ```

5. **df -i** (Disk Free with Inodes) - Displays information about free inodes on each file system.
   ```
   df -ih
   ```

6. **du -d 1 -h / | grep total** (Display the total size of all files and directories)
   ```
   du -d 1 -h /
   ```

7. **df --output=avail,used,pct-usable /` (Display available space, used space, and percentage of usable space for each file system)
   ```
   df --output=avail,used,pct-usable /
   ```
