Here's an example of how you can write pytest tests for a function that reverses a string:

```python
import pytest

def reverse_string(s):
    return s[::-1]

# Test case 1: Reversing a simple string
def test_reverse_string_simple():
    assert reverse_string("hello") == "olleh"

# Test case 2: Reversing an empty string
def test_reverse_string_empty():
    assert reverse_string("") == ""

# Test case 3: Reversing a string with spaces and punctuation
def test_reverse_string_with_spaces_and_punctuation():
    assert reverse_string("Hello, World!") == "!dlroW ,olleH"

# Test case 4: Reversing a very long string
def test_reverse_string_long_string():
    import random
    long_string = ''.join(random.choice('abcdefghijklmnopqrstuvwxyz') for _ in range(1000))
    assert reverse_string(long_string) == long_string[::-1]

# Test case 5: Edge case - reversing an empty string with spaces and punctuation
def test_reverse_string_empty_with_spaces_and_punctuation():
    assert reverse_string("   ") == "   "
```

In this example, we have five test cases:

- `test_reverse_string_simple`: Tests the function with a simple string.
- `test_reverse_string_empty`: Tests the function with an empty string.
- `test_reverse_string_with_spaces_and_punctuation`: Tests the function with a string containing spaces and punctuation.
- `test_reverse_string_long_string`: Tests the function with a very long string.
- `test_reverse_string_empty_with_spaces_and_punctuation`: Tests the function with an empty string that contains spaces and punctuation.

Each test case checks if the output of the `reverse_string` function matches the expected result. If all tests pass, it gives confidence that the function works correctly for different inputs.
