You can use the `systemctl` command to inspect a systemd service without modifying it.

Here are some examples of commands you can use:

1. **List all services**: `systemctl list-units --type=service`

This will show you a list of all running and inactive services, including their status and description.

2. **Show details about a specific service**: `systemctl show <service_name>`

Replace `<service_name>` with the name of the service you want to inspect. This will show you detailed information about the service, such as its configuration file, dependencies, and unit file.

3. **Check if a service is enabled or disabled**: `systemctl is-enabled <service_name>`

This will tell you whether the service is enabled (i.e., it's started when the system boots) or disabled.

4. **Start or stop a service**: `systemctl start/stop <service_name>`

Replace `<service_name>` with the name of the service you want to control. The `start` command will start the service, while the `stop` command will stop it.

5. **Check the status of a service**: `systemctl status <service_name>`

This will show you the current status of the service, including whether it's running or not.

6. **Show the unit file for a service**: `systemctl show --property=unit-file <service_name>`

This will show you the contents of the unit file that controls the service.

7. **Check the dependencies of a service**: `systemctl show --property=after <service_name>`

This will show you the services that are required to be started before this one can start.

8. **Check the configuration file for a service**: `systemctl show --property=configuration-file <service_name>`

This will show you the path of the configuration file used by the service.

These commands should give you all the information you need about your systemd services without modifying them.
