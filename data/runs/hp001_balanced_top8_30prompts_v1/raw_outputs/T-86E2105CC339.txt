 Here are some read-only Linux commands that can help you inspect disk usage:

1. **df**: The `df` command displays the amount of disk space used and available on your file systems. It's a quick way to get an overview of your disk usage. You can use it with options like `-h` for human-readable format, `-T` to show the file system type, and `-i` to display inode usage.

   Example: `df -Thi`

2. **du**: The `du` command provides a report on disk usage, showing the total size of each directory and its subdirectories. When used without options, it lists directories in the current working directory. Useful options include `-h` for human-readable format, `-s` to display only a total for each argument (which can be a file or directory), and `-c` to show a grand total at the end.

   Example: `du -sh *` (lists sizes of all files in the current directory) or `du -sh /` (displays total disk usage for the root file system).

3. **ncdu**: `ncdu` is a ncurses-based disk usage analyzer. It's especially useful for finding large directories and files. It recursively lists directories by size, with the largest ones first. Press 'h' for help and navigate using arrow keys or 'j/k'.

   To install `ncdu` on Ubuntu, you can run: `sudo apt-get install ncdu`. Then, simply execute `ncdu` from the command line to start analyzing disk usage.
